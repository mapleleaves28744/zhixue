# 01_前端页面总览

> 文档状态：**当前实现事实源**
> 同步日期：2026-06-08

## 当前前端形态

当前前端不是常规 React 业务组件页面，而是：

```text
Next.js 16 App Router
  → StitchFrame iframe 壳层
  → frontend/public/stitch-pages/*.html
  → zhixue-static-api.js / 页面脚本
  → FastAPI /api/v1
```

Next.js 负责顶层路由、全屏 iframe 壳层和约 200ms 路由淡入。业务展示和交互主要位于 8 个 Stitch HTML 页面；**例外：`/assistant` 已 React 化**（`AssistantPageClient`），不再嵌入 `assistant.html`。其余页面除非任务明确批准组件化，否则继续维护 Stitch 页面。

## 当前共享能力

- `frontend/components/StitchFrame.tsx`：iframe 承载与 Framer Motion 淡入。
- `frontend/public/stitch-pages/zhixue-static-api.js`：Token、统一请求和常用 API 方法。
- `frontend/public/stitch-pages/zhixue-ui.js`：空状态、Skeleton、Toast、页面 mascot、滚动进入效果。
- `frontend/public/stitch-pages/stitch-shared.css`：共享视觉样式。
- `frontend/components/assistant/`：`/assistant` React 页（快速 Tutor + 智能体任务流）。
- `frontend/public/stickers/`、`frontend/public/brand/`：本地 IP 与品牌资产。

## 当前限制

1. 没有 Next middleware 路由鉴权；主要依赖 Token、API 401 和页面跳转。
2. 静态页面中仍存在部分页内请求逻辑，不完全遵守 React `services/` 分层。
3. dashboard 趋势、知识图谱视觉和 Agent 详情展示仍可增强。
4. 当前不建设教师端与管理员端页面。
5. 旧的详细页面设计文档用于规划参考，不代表页面已经按其中组件结构实现。
