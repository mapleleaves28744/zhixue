## 诊断输入输出

诊断基于练习提交、答案正确性、错题、课程知识点和历史表现生成。输出包含总结、薄弱知识点、错因和行动建议，并保存为可回看的诊断报告。

## 薄弱点与错因

当前以答题证据和 LLM/规则分析结合识别薄弱点。结论必须绑定题目或知识点证据，不能仅凭聊天内容推断。遗忘风险属于后续增强，目前不应描述为成熟算法。

## 推荐与学习路径

Recommend Agent 和 Learning Path Service 根据诊断、画像、记忆和已有路径生成下一步建议。推荐必须说明理由；路径项支持完成状态。推荐反馈闭环和排序评估仍需补充。

## 评估指标

- 诊断与实际错题是否一致。
- 推荐是否绑定可解释证据。
- 路径是否避免重复已掌握内容。
- 同一用户连续学习后的建议是否合理变化。
- 不同用户的数据和推荐是否严格隔离。
