## 2026-06-06：当前实现事实源校准

本次校准解决旧设计方案、规划文档与实际代码不一致时容易误导后续开发的问题。

### 新增

- 新增 `docs/当前实现基线.md`，集中记录当前技术栈、页面形态、主链路和明确缺口。
- 新增 `docs/00_文档规范/04_文档事实源与状态规则.md`，定义实现事实、设计约束和规划参考的优先级。
- 新增 `scripts/export_implementation_docs.py`，从 FastAPI OpenAPI 与 SQLAlchemy metadata 自动导出当前接口和数据库清单。
- 新增当前 OpenAPI 快照、89 个 HTTP 操作清单和 28 张 ORM 表清单。

### 更新

- 更新 `AGENTS.md`、根目录 `README.md` 与文档索引，要求后续开发先核对当前实现事实源。
- API 文档按当前 FastAPI Router 重新生成；未实现的管理员后台、Token 刷新和退出接口不再描述为已完成。
- 前端页面与路由文档更新为当前 Next.js App Router + `StitchFrame` + Stitch 静态页架构。
- 更新系统架构、功能完成度、PRD、Wiki、Agent、自进化、RAG 等文档的状态说明，避免将目标蓝图误认为当前实现。

### 维护约定

Router、Schema 或 SQLAlchemy Model 变化后执行：

```powershell
python scripts/export_implementation_docs.py
```

生成文件应与对应代码变更一并提交。
