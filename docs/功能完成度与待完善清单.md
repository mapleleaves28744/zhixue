## 当前主链路

```text
注册登录 → 创建课程 → 上传资料 → 解析 → 切片 → 向量化
→ 知识点抽取 → RAG → Wiki → Tutor → 资源
→ 练习 → 错题 → 诊断 → 画像/记忆 → 自进化 → 推荐 → Agent 日志
```

真实验收使用 `xiaomi_mimo / mimo-v2.5`，`fallback_used=false`。详见 `19_测试方案/13_真实LLM主链路与Next安全专项验收记录.md`。

## 当前明确缺口

### P0：比赛演示可靠性

1. 一键初始化完整演示用户数据，包括练习、诊断、推荐和历史 Agent 日志。
2. 浏览器级自动化 E2E，覆盖登录到自进化。
3. Docker Compose 全栈启动验收。
4. 更稳定的真实模型超时、重试和成本记录。

### P1：创新展示深度

1. Wiki 图谱复杂布局、筛选与路径推理。
2. Agent 调用链详情与 Review 结果展示。
3. 自进化策略前后差异、证据与风险确认强化。
4. 学习趋势、掌握度、推荐反馈真实化。

### P2：工程增强

1. 升级 Redis 至 5+，将 Agent 实时事件从 Pub/Sub 兼容模式切换为 Redis Stream。
2. 完整会话历史侧栏、任务搜索和人工恢复控制。
3. 将 20 条真实 MiMo Agent 场景接入持续回归和指标趋势展示。
4. 大文件异步解析与进度。
5. MinIO、完整 Microsoft GraphRAG community summaries、Global/Local/DRIFT 查询、cross-encoder/LLM rerank 等增强能力。
6. 5 个 Agent 已迁移到 `structured_chat()`（quiz/evolution/review/memory/profile）。
7. 语音交互：MiMo Token Plan TTS/ASR 已接入；数字头像仍待做。
8. 移动端适配：PWA + 全站响应式重构。

- 管理员后台：当前无页面、无 `/api/v1/admin/*`，不应宣称已实现。
- 旧 React `/student/*` 页面：不建设。
