## 页面与认证

| 模块 | 当前能力 | 主要入口 |
|---|---|---|
| 首页与导航 | 品牌首页、登录注册弹窗、8 个学生端入口 | `/`、`/home` |
| 用户认证 | 注册、登录、JWT、当前用户 | `/api/v1/auth/*` |
| 课程空间 | 课程创建、编辑、归档与选择 | `/courses` |
| 学习仪表盘 | 学习摘要、推荐与 Agent 统计 | `/dashboard` |

## 知识与问答

| 模块 | 当前能力 | 主要入口 |
|---|---|---|
| 资料管理 | 上传、解析、切片、向量化、状态查询 | `/knowledge` |
| LLM Wiki | 生成、详情、来源、版本、编辑、回滚 API | `/knowledge` |
| RAG/知识图谱 | 课程内检索、知识点与关系数据 | `/knowledge` |
| Tutor | 基于资料与 Wiki 回答，返回引用和关联知识点 | `/assistant` |
| 资源生成 | 生成 Markdown 学习资源并可保存 | `/assistant` |

## 练习与个性化

| 模块 | 当前能力 | 主要入口 |
|---|---|---|
| 题库练习 | 生成、答题提交、错题记录 | `/practice` |
| 学习诊断 | 诊断报告、薄弱点、历史诊断 | `/practice` |
| 学习路径与推荐 | 路径生成、完成项、下一步推荐 | `/path-profile`、`/dashboard` |
| 学生画像与记忆 | 查看、重建、反思、删除 | `/path-profile` |
| 自进化策略 | 分析、应用、回滚、证据和风险 | `/path-profile` |
