## Query 参数

- `course_id`：当前课程上下文，主要用于知识库、助手、练习等页面。
- `auth=login|register`：品牌首页打开认证弹窗。
- `redirect`：登录成功后的目标路径。
- `api_base`：开发调试时覆盖后端 API 地址。

## 权限现状

当前没有 `middleware.ts`。登录态保存在浏览器侧，Stitch API 桥在请求中携带 Bearer Token；API 返回 401 时清理会话并跳转登录入口。真正的数据权限由后端 JWT 依赖和 Service 所有权校验保证。

## 导航约束

iframe 内跨顶层页面跳转使用父页面导航，保持 Next 路由和地址栏同步。当前范围冻结：不新增 `/teacher/*`、`/admin/*` 或旧 `/student/*` 路由。
