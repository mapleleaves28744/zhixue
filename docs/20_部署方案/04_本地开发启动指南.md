## 原则

当前阶段先把本地主链路打通，再集中处理 Docker 部署。日常开发默认使用本地 Python、Node、本机 PostgreSQL 和本机 Redis 服务。

## 本地环境变量

`.env` 默认应使用本机数据库和缓存：

```env
DATABASE_URL=postgresql+asyncpg://zhixue:zhixue_password@localhost:5432/zhixue
REDIS_URL=redis://localhost:6379/0
```

不要在本地开发 `.env` 中使用 Docker 内部主机名：

```env
DATABASE_URL=postgresql+asyncpg://zhixue:zhixue_password@postgres:5432/zhixue
REDIS_URL=redis://redis:6379/0
```

上面的 `postgres`、`redis` 只用于 Docker Compose 内部网络。

## 数据库与缓存

本地开发默认使用本机 PostgreSQL/Redis。请先确认：

1. PostgreSQL 正在监听 `localhost:5432`；
2. 已创建用户 `zhixue` 和数据库 `zhixue`；
3. Redis 正在监听 `localhost:6379`；
4. `python -m alembic upgrade head` 能连接并执行 migration。

Docker 中的 PostgreSQL/Redis 只作为部署阶段或临时备选，不作为日常开发默认依赖。

## LLM 配置

无真实 Key 时：

```env
LLM_PROVIDER=mock
EMBEDDING_PROVIDER=mock
```

该配置可运行普通 Tutor、Wiki、资源、练习和诊断等支持 Mock 的链路。当前 `/assistant` LangGraph Agent Runtime 以 `allow_mock_fallback=False` 获取 Provider，因此智能体模式仍需要真实 LLM Key；不要把普通 Mock 链路描述成“无 Key 完整 Agent”。

接入 OpenAI-compatible 服务时：

```env
LLM_PROVIDER=compatible
LLM_BASE_URL=https://api.xiaomimimo.com/v1
LLM_API_KEY=你的_API_KEY
LLM_MODEL_NAME=mimo-v2.5-pro
EMBEDDING_PROVIDER=mock
```

## 验证顺序

1. 后端 `/health` 正常；
2. `python -m alembic upgrade head` 正常；
3. `python -m pytest` 或相关测试通过；
4. 前端页面可打开；
5. 完成注册、建课、资料上传、解析、切片、Wiki 生成等主链路验证。

Docker Compose 在部署阶段再作为完整验收项。

## 从演示服务器同步数据库（队友 / AI 一键）

若需要和线上演示环境（`49.235.190.234`）一致的 PostgreSQL 数据（Wiki、切片、stu_01 等），**不要直连远程库**，用脚本把 dump 拉到本机再导入。

### 前置条件

1. 本机已安装 **PostgreSQL 17**（或 16+）客户端，含 `pg_restore`、`psql`（Windows 安装 PG 时勾选 Command Line Tools）
2. 本机 PostgreSQL 服务已启动，默认监听 `localhost:5432`
3. 本机 **Redis** 已启动（`localhost:6379`）
4. 向负责人索取 SSH 密码，**仅通过环境变量传入，勿写入 git**

### 一键命令（PowerShell）

```powershell
cd <项目根目录>
pip install paramiko
$env:ZHIXUE_SSH_PASSWORD='向负责人索取'
python scripts/sync_dev_from_server.py
```

脚本会：

1. SSH 到演示服务器，在 Docker 容器 `zhixue-postgres` 内执行 `pg_dump`
2. 下载到 `data/zhixue-remote.dump`
3. 若本地无 `.env`，从 `.env.example` 生成并改成本地 `localhost` 配置
4. 重建本地 `zhixue` 库并 `pg_restore` 导入
5. 尝试执行 `alembic upgrade head`

可选参数：

```powershell
python scripts/sync_dev_from_server.py --skip-restore    # 只下载 dump
python scripts/sync_dev_from_server.py --with-storage    # 同步 storage/uploads
```
