## 当前运行方式

## 部署优先级

当前阶段采用“本地优先，Docker 后置”的工程策略。

1. 功能开发和主链路打通优先使用本地开发环境，包括本机 PostgreSQL 和 Redis。
2. Docker Compose 用于部署专项、第21阶段和比赛演示环境整理。
3. 非部署任务不要因为 Docker 容器问题阻塞业务功能开发。
4. Docker 问题应记录为部署 TODO，等本地主链路稳定后集中处理。

## 环境分层

| 环境 | 用途 | 当前优先级 |
|---|---|---|
| 本地开发环境 | 日常开发、接口联调、LLM Provider 调试、本机数据库 migration 验证 | 最高 |
| 本地 Docker Compose | 后续部署模拟、演示环境、依赖统一 | 后置 |
| 服务器部署 | 比赛展示或远程访问 | 后置 |

## 当前验收原则

在主链路未完整稳定前，优先验收：

1. `python -m pytest` 或关键后端接口可运行；
2. `python -m alembic upgrade head` 可运行；
3. FastAPI 本地 `/health` 正常；
4. 前端本地开发服务可访问；
5. Mock Provider 和真实 OpenAI-compatible Provider 可切换。

Docker Compose 可启动仍是最终工程目标，但不作为当前每个业务任务的强制前置。

本地默认连接：

```env
DATABASE_URL=postgresql+asyncpg://zhixue:zhixue_password@localhost:5432/zhixue
REDIS_URL=redis://localhost:6379/0
```

## Phase 3.1 稳定演示启动

LangGraph Agent 与沉浸课堂演示必须同时启动 FastAPI、arq Worker、前端和 OpenMAIC。推荐使用：

```powershell
scripts/start_phase31_demo.ps1
```

脚本会执行 Alembic migration，检查 `8000`、`3000`、`3001` 端口是否被旧进程占用，并检查是否已有 `arq app.workers.agent_worker.WorkerSettings` 进程。若检测到旧 Worker，脚本默认拒绝继续启动，避免新旧 Worker 共享 Redis 队列后抢任务导致 Agent 演示长时间等待。

```text
FastAPI Backend: http://127.0.0.1:8000
arq Agent Worker: app.workers.agent_worker.WorkerSettings
Next.js Frontend: http://127.0.0.1:3000
OpenMAIC Engine: http://127.0.0.1:3001
```

若端口被占用，不会自动杀进程；请先停止旧服务，或显式传入其他端口：

```powershell
scripts/start_phase31_demo.ps1 -BackendPort 8002 -FrontendPort 3002 -OpenMAICPort 3001
```

若确认已有 Worker 就是当前分支最新代码，可显式允许：

```powershell
scripts/start_phase31_demo.ps1 -AllowExistingWorker
```

对应演示入口：

```text
http://127.0.0.1:3000/assistant?api_base=http%3A%2F%2F127.0.0.1%3A8000%2Fapi%2Fv1
```

稳定性冒烟验收：

```powershell
python scripts/agent_demo_check.py --base-url http://127.0.0.1:8000/api/v1
```

该脚本会通过真实 HTTP API 创建学生、课程和 Agent 会话，发送画像更新与学习路径两轮消息，校验工具调用、事件、最终消息和画像证据是否落库。

OpenMAIC 详细运行、服务器环境变量和安全边界见：[06_OpenMAIC沉浸课堂本地运行指南.md](06_OpenMAIC沉浸课堂本地运行指南.md)。

## 环境变量

真实密钥只放在未提交的 `.env`/`.env.local`。仓库仅维护 `.env.example`。核心变量包括数据库、Redis、JWT、LLM Provider、模型与 API Base URL。

若服务器需要随仓库一起启动 OpenMAIC，请至少显式填写：

```env
NEXT_PUBLIC_API_BASE_URL=https://your-domain.example/api/v1
HTTP_PORT=80
OPENMAIC_PORT=3001

DATABASE_URL=postgresql+asyncpg://zhixue:zhixue_password@postgres:5432/zhixue
REDIS_URL=redis://redis:6379/0

OPENMAIC_ENABLED=true
OPENMAIC_BASE_URL=http://openmaic:3000
OPENMAIC_PUBLIC_BASE_URL=https://your-domain.example:3001
OPENMAIC_INTERNAL_TOKEN=replace-with-a-long-random-service-token
OPENMAIC_SIGNING_SECRET=replace-with-a-different-long-random-signing-secret

XIAOMI_API_KEY=...
XIAOMI_BASE_URL=...
XIAOMI_MODELS=mimo-v2.5
DEFAULT_MODEL=xiaomi:mimo-v2.5
TTS_XIAOMI_MIMO_API_KEY=...
TTS_XIAOMI_MIMO_BASE_URL=...
ASR_XIAOMI_MIMO_API_KEY=...
ASR_XIAOMI_MIMO_BASE_URL=...
```

说明：

1. `OPENMAIC_BASE_URL` 给 backend/worker 使用，容器内固定走 `http://openmaic:3000`。
2. `OPENMAIC_PUBLIC_BASE_URL` 给浏览器跳转播放使用，应填写服务器公网地址或域名。
3. `OPENMAIC_PORT` 默认暴露宿主机 `3001`，保持和当前本地演示一致，便于独立调试课堂引擎。
4. OpenMAIC 当前不自动复用 `LLM_API_KEY` 作为 MiMo 配置；服务器部署时请显式填写 `XIAOMI_*`、`TTS_*`、`ASR_*` 变量。
5. `docker-compose.prod.yml` 会强制 backend/worker 在容器内使用 `postgres`、`redis`、`openmaic` 服务地址，不会复用本地 `.env` 里的 `localhost` 连接串。

## 数据库与模型

本地默认使用 PostgreSQL/pgvector 和 Redis 服务；数据库结构通过 Alembic 管理。LLM 通过统一 Provider 调用，缺少 Key 时使用 Mock，真实演示需确认 `fallback_used=false`。

## 队友从演示服务器同步本地库

演示服务器（默认 `49.235.190.234`）使用 Docker 内 **PostgreSQL 17 + pgvector**，不对外暴露 5432。队友开发时应把远程库 **dump 到本机** 再导入，而不是长期直连远程数据库。

一键脚本：`scripts/sync_dev_from_server.py`（需 `ZHIXUE_SSH_PASSWORD`）。详细步骤与给 AI 的提示词见 **`04_本地开发启动指南.md`** 中「从演示服务器同步数据库」一节。

## 当前服务器 Compose 启动

当前仓库已经把 `third_party/openmaic` 一并纳入版本管理。服务器按下面步骤即可按“本地四进程并行”的近似方式启动：

```powershell
cp .env.example .env
# 按上文填写数据库、Redis、OpenMAIC 和 MiMo 变量

docker compose -f docker-compose.prod.yml up -d --build
docker compose -f docker-compose.prod.yml ps
```

当前 `docker-compose.prod.yml` 会启动：

```text
postgres   pgvector/pgvector:pg17
redis      redis:7-alpine
openmaic   third_party/openmaic -> next start (host port 3001)
backend    FastAPI + alembic upgrade
worker     arq app.workers.agent_worker.WorkerSettings
frontend   Next.js
nginx      对外 80 端口
```

推荐启动后检查：

```powershell
docker compose -f docker-compose.prod.yml logs openmaic --tail=100
docker compose -f docker-compose.prod.yml logs backend --tail=100
docker compose -f docker-compose.prod.yml logs worker --tail=100
```

以及：

```text
http://server-ip/health
http://server-ip:3001/api/health
```
