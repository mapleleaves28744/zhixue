## 1. 计划目标

本计划用于在不破坏现有功能、不一次性重写项目的前提下，逐步提高以下质量：

1. 生产配置和认证安全；
2. 用户、课程和资料权限隔离；
3. 资料上传、解析、切片和向量化稳定性；
4. Agent 审核、工具调用、重试、幂等和事件流可靠性；
5. RAG 检索、引用和 Embedding 一致性；
6. 前后端 API 契约和前端运行稳定性；
7. 测试、部署、文档和可维护性。

本文不授权一次性删除旧 Agent、重写前端、修改数据库结构或引入新框架。每项任务都应单独复现、单独测试、单独提交、单独验收。

## 3. 单任务执行规范

每个任务遵循：

```text
确认当前分支和工作区
  → 复现问题
  → 新增失败测试
  → 最小修改
  → 目标测试
  → 受影响模块回归
  → 全量回归
  → 浏览器或专项验收
  → 更新事实文档
  → 单独提交
```

每个提交应满足：

1. 不混入无关格式化和重构；
2. 不删除未经确认的旧功能；
3. 不降低已有测试数量；
4. 不用 Mock 冒充真实 Provider 验收；
5. 涉及 Router、Schema、Model 时同步实现文档；
6. 涉及数据库结构时提供可执行的 Alembic Migration；
7. 验收未通过时只能标记“实现完成但验收未通过”。

## 5. 第一阶段：安全、越权与核心正确性

### T01 生产环境安全配置强校验

**优先级：P0｜难度：简单｜数据库变化：无**

- **任务目标**：阻止生产环境使用默认 JWT Secret、`debug=True` 或危险 CORS。
- **涉及文件**：`backend/app/core/config.py`、`backend/app/main.py`、配置测试。
- **修改前行为**：部署漏配环境变量时，应用仍可能使用开发默认值启动。
- **准备修改**：
  1. 仅在 `APP_ENV=production` 时执行强校验；
  2. JWT Secret 不得为默认值，且必须达到最低长度；
  3. `DEBUG` 必须为 `false`；
  4. CORS 不得使用任意来源；
  5. 错误信息不得回显真实密钥。
- **预期行为**：开发环境保持兼容；不安全生产配置直接启动失败；安全生产配置正常启动。
- **可能影响**：生产 Docker、部署文档、CI 环境变量。
- **测试验证**：覆盖默认 Secret、短 Secret、Debug、危险 CORS、安全生产配置和开发默认配置。
- **回滚方式**：`git revert <commit>`；无 Migration。
- **建议提交**：`fix(config): reject insecure production defaults`

- **涉及文件**：`frontend/lib/api.ts`、`frontend/components/StitchFrame.tsx`、`frontend/public/stitch-pages/zhixue-static-api.js`。
- **修改前行为**：URL 参数 `api_base` 可以指定任意 HTTP 地址并持久化到 localStorage。
- **准备修改**：
  1. 生产环境禁用 URL 覆盖；
  2. 开发环境仅允许 localhost 或配置白名单；
  3. 非法值不写入 localStorage；
  4. Stitch iframe 只接收宿主传入的受信 API 地址。
- **预期行为**：恶意 `api_base` 不改变登录和 API 请求目标。
- **可能影响**：Stitch iframe、本地联调、部署环境变量。
- **测试验证**：合法 localhost 可用；任意外部地址被拒绝；登录仍访问正式后端。
- **回滚方式**：`git revert <commit>`；无 Migration。
- **建议提交**：`fix(frontend): restrict dynamic api base overrides`

- **可能影响**：知识点抽取、Embedding、Wiki、RAG。

- **回滚方式**：`git revert <commit>`；若增加状态枚举字段则单独 Migration。

## 12. 阶段停止条件

出现以下任一情况时，不继续下一任务：

1. 当前提交导致已有测试下降；
2. 新 API 与对应 Stitch/React 页面尚未联调；
3. Migration 不能 upgrade 和 downgrade；
4. 权限测试不能证明用户隔离；
5. Review 失败仍可能保存最终回答；
6. Agent 任务仍能产生重复资源；
7. 前端 typecheck 或 build 失败；
8. 当前实现事实文档没有同步；
9. 真实 Provider 验收发生 Mock fallback；
10. 浏览器核心链路出现未解释的控制台错误。
