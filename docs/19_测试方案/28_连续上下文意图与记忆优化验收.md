# 连续上下文、意图识别与记忆优化验收

> 日期：2026-09-30。状态：2026-09-30 历史功能回归；对应业务实现已于 2026-10-07 随 `61465d8` 提交。
> 当时验收模型：OpenAI-compatible / Qwen 3.8 Flash；根目录 `.env` 与 `backend/.env` 已同步。密钥不进入本记录或 Git。

## 实现范围

| 能力 | 当前落点 |
|---|---|
| 连续问答 | Tutor 和 Agent 共用会话，最终模型读取本人、同课程、当前回合之前的完整历史；固定排队任务的消息边界 |
| 长上下文 | 确定性原文投影、重要原文后台选择、原消息保留、约束投影、来源索引与版本栅栏 |
| 意图识别 | 普通知识问答直接回答；组合、补充与修订请求按需语义解析；契约记录子任务、工具、主题、排除项、来源与修订号 |
| 可靠执行 | 请求去重、Tutor 租约和状态查询、写工具业务操作身份、已提交结果复用、未知在途写入停止自动重做 |
| 任务修订 | 停止原任务并等待在途步骤结束，再建立新的修订任务；权限和确认重新检查；保留原始来源 |
| 记忆写入 | 持久提炼任务、认领/重试/提交栅栏、合法证据校验、候选合并、冲突待确认、来源重复不重复强化 |
| 记忆读取 | 当前课程与明确 global 作用域、相关性排序、有效期、热/冷层、遗忘抑制；有权限过滤的历史搜索 |
| 记忆管理 | Stitch 页面查看证据、纠正、归档、遗忘、明确恢复；React 和 Stitch 共用运行时 API 地址 |

续作修复的实际缺陷：迟到历史列表覆盖正在生成的消息；Stitch iframe 忽略 API 地址；记忆模型提炼未传入 user_id；检索和审查被错误要求生成新产物；多主题资源没有把独立 topic 传到生成模型；多次任务修订可能丢失最初来源；Markdown 代码注释被误取为标题；检索提示覆盖已生成资源的完成消息；任务展示仍持有旧规则契约。

## 适用限制与后续实验

- 当前未提供 Qwen 专用 tokenizer 文件，预算使用保守估算；超长本轮必需输入仍需拆分。
- 后台语义摘要选择真实原文，不自由生成无来源事实；后台提炼/摘要持续运行需要 arq Worker。
- 任务修订采用取消并重新执行，不是任意步骤中的原地 steering；不明状态的业务写入需要核对。
- 同义遗忘抑制覆盖规范事实键与已知别名；不确定的语义相似候选待确认，不能保证理解所有自由表达。
- 本地缺少 sentence-transformers 时课程检索使用已有关键词回退；本次不能据此宣称已验证向量检索质量。
- 音频 Provider 仅在 MiMo 地址下调用 MiMo TTS；当前 Qwen 文本配置使用明确标记的 Mock 音频，不将其计入真实模型效果。
- 默认 Turbopack 构建遇到字体模块解析错误；Webpack 生产构建通过。该构建器问题与聊天/记忆功能回归分开记录。
- 留出集盲测、无历史/近期历史/压缩历史/长期记忆消融、灰度分组和大规模并发仍是后续实验，不宣称上述有限回归已证明全部规划准确率目标。
