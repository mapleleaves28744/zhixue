## 修复准入规则

```text
复现与根因定位
  → 新增失败测试
  → 最小修复
  → 受影响模块回归
  → 全量回归
  → 浏览器或专项验收
  → 更新事实源和缺陷状态
```

任何缺陷只有在真实运行或自动测试形成证据后才能标记“已修复”；只修改代码未通过验收时标记“实现完成但验收未通过”。
