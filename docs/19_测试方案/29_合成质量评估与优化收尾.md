# 连续上下文、意图识别与记忆优化收尾

> 2026-10-01；当前工作区实现与本地验收，未提交。本文补充 [9 月 30 日验收](28_连续上下文意图与记忆优化验收.md)。

## 完成范围

本次完成授权的自动标签合成评估、上下文和记忆消融、本地并发与进程故障验证，并将发现的缺陷修入业务代码。真实文本模型为 Qwen `qwen3.8-flash`，没有修改根目录或后端 `.env`。本轮没有重新设计前端；沿用已接入的会话和记忆管理入口。

主要修复：

1. 上下文使用 UTF-8 字节保守边界；超长必需输入明确拒绝并要求拆分，早期摘要保留独立容量。可配置本地 tokenizer，当前没有声称已接入 Qwen Flash 专用 tokenizer。
2. 会话要求支持撤销、否定和替换；单轮、会话限定要求及敏感信息不进入长期学习偏好。
3. 自然交付、组合主题与最新修订经过语义校验，执行主题必须有当前来源；无法校验时澄清。执行器保存保守回退契约，避免继续执行旧候选。普通问答中的比较描述不授权工具，不按交付主题的字面匹配规则误拒绝。
4. 资料支持序号和唯一标题定位；全文总结分批读取全部已解析切片并分层合并，超出批次上限要求拆分，拒绝空结果和 Mock 回退。读取全部切片不意味着摘要包含全部细节。
5. 练习题持久化顺序号，支持“第二题 B 选项”；旧题没有可靠顺序时要求补充题干，避免猜测。
6. 记忆反思及 Tutor 请求在锁定、认领、完成和失败时刷新 SQLAlchemy identity map，拒绝旧租约和提炼期间遗忘后的旧对象覆盖。未知同义偏好在遗忘后进入待确认。
7. Agent 回答保存来自实际 Provider 响应或问答工具结果的模型来源；规则澄清不伪填模型名称。语义校验失败只记录异常类型，便于排查且不输出密钥。

## 失败、恢复与预算

真实模型调用统一经过 `evaluation_budget.py`：SQLite 事务预占预算，结构化重试逐次计数，评估传输层每次只做一次 HTTP 尝试。成功按返回 usage 结算；失败、崩溃、缺少 usage 按全部预留计入。新增连续传输失败熔断，避免持续消耗额度。

预算上限 3,000,000；最终保守计入 **1,493,527**，剩余 **1,506,473**。662 次成功返回 usage 共 904,720；36 次传输失败因没有 usage 保守计入 588,807，无 pending。该数不是厂商精确账单，也不包含其他独立用户进程的调用。明细见 `budget-report.json` 与 `budget-calls.json`，没有保存密钥或请求正文。

36 次上下文传输失败保留在原 release 报告；恢复脚本只重试这些失败，36 次恢复均成功。原故障注入发现 6 个旧租约保护失败，原报告保留，修复后 42 项通过。HTTP 失败与历次恢复嵌套保存，不选择性删除失败或挑选最好一次。

仅停止了本次创建的 8017 评估服务，未停止用户已有服务。若用户已有业务进程启动早于本次修改，需要正常重启后才加载新代码。
