## 赛题目标

项目对应中国软件杯 A3 赛题，目标是面向高校专业课程构建个性化资源生成与多智能体学习空间。当前演示课程以《数据结构》为主，核心不是聊天，而是可持续学习闭环。

## 功能需求映射

| 赛题要求 | 当前实现证据 |
|---|---|
| 完整课程知识库 | 资料上传、解析、切片、Embedding、知识点、Wiki |
| 个性化资源生成 | Tutor、Resource、Quiz、Recommendation |
| 多智能体协作 | 13 个 Agent、Orchestrator、Agent run 日志 |
| 学习状态分析 | 练习提交、错题、诊断、画像、长期记忆 |
| 自适应更新 | Evolution 策略生成、应用与回滚 |
| 可演示闭环 | 真实 LLM 23 步主链路验收 |

## 非功能与评审重点

- 可解释：Wiki 来源、Tutor 引用、推荐理由、策略证据。
- 可控：学生数据隔离，自进化有风险等级、版本和回滚。
- 可落地：本地优先启动，Mock 可兜底，真实 Provider 已验收。
- 创新可见：前端需展示 Wiki、Agent 调用链、自进化策略差异和诊断依据。

## 范围取舍

学生端闭环优先。教师端冻结；管理员后台当前未实现，不纳入已完成功能。比赛前优先补演示数据、浏览器 E2E、创新点可视化和部署稳定性。
