## 1. 系统是什么

**智学工坊**是一个面向高校课程的个性化学习空间，核心能力不是「单纯聊天」或「资料网盘」，而是围绕一门课程形成完整闭环：

```text
上传资料 → 解析切片向量化 → 知识点抽取 → LLM Wiki
→ AI 答疑 / 智能体 → 个性化资源生成 → 练习与诊断
→ 学生画像 / 长期记忆 → 自进化策略 → 学习路径与推荐
```

你在使用时应关注三个创新点：

| 创新点 | 你会看到什么 |
|--------|-------------|
| **LLM Wiki** | 知识点页面带来源追溯、版本历史，不是普通笔记 |
| **多智能体** | `/assistant` 智能体模式可展开执行步骤、工具调用、Review 结果 |
| **自进化** | 系统根据学习行为更新策略版本，可查看证据、风险等级并回滚（不是自动改代码） |

## 2. 如何打开与登录

### 2.1 访问地址

| 环境 | 地址 | 说明 |
|------|------|------|
| **线上演示站** | http://49.235.190.234/ | 队友日常联调、答辩演示 |
| 本地开发 | http://127.0.0.1:3000/ | 需自行启动前后端 |

后端健康检查（可选）：`http://49.235.190.234/api/v1` 对应的前端会自动请求 API；也可直接访问 `/health` 确认服务正常。

### 2.2 演示账号（线上）

| 字段 | 值 |
|------|-----|
| 用户名 | `stu_01` |
| 密码 | `123456` |

该账号通常已绑定《数据结构》公有课程及历史学习数据，适合直接体验 Wiki、练习、画像等，无需从零上传资料。

### 2.3 注册新账号

1. 打开首页 `/`
2. 点击右上角 **「登录」**，在弹窗中切换到 **「注册」** 标签
3. 填写用户名、密码（及必要信息）后提交
4. 注册成功后会提示登录；登录成功后自动跳转到 `/home`

> 也可直接访问 `/login` 或 `/register`，系统会重定向到 `/?auth=login` 或 `/?auth=register`。

### 2.4 登录

1. 首页点击 **「登录」**
2. 输入用户名和密码
3. 登录成功后进入 **学习首页** `/home`

登录态保存在浏览器 `localStorage`（Token）。退出登录可点击各 Stitch 页面右上角的退出按钮（部分页面提供）。

### 2.5 指定后端地址（高级）

若前端与后端不在同一域名，可在 URL 中附加 `api_base` 参数，例如：

```text
http://49.235.190.234/register?api_base=http%3A%2F%2F49.235.190.234%2Fapi%2Fv1
```

系统会将该地址写入 `localStorage` 的 `zhixue_api_base`，后续所有 API 请求都会使用它。**一般线上演示无需手动设置。**

## 3. 界面与导航

登录后，左侧（桌面端）会出现固定 **侧边导航栏**，各页面图标一致：

| 图标 | 路由 | 名称 | 主要用途 |
|------|------|------|----------|
| 🏠 | `/home` | 学习首页 | 总览、快捷提问、学习分析 |
| 📚 | `/courses` | 课程空间 | 创建/管理课程 |
| 🤖 | `/assistant` | AI 学习助手 | 答疑、智能体、资源生成 |
| 📝 | `/practice` | 练习与诊断 | 出题、答题、错题、诊断 |
| 📊 | `/dashboard` | 学习仪表盘 | 数据概览、推荐任务 |
| 📖 | `/knowledge` | 课程知识库 | 资料、Wiki、图谱 |
| 🛤️ | `/path-profile` | 学习路径与画像 | 画像、记忆、路径、自进化 |

额外页面：

- **`/`** — 未登录时的品牌介绍页（含登录/注册）
- **`/evolution`** — 自进化策略仪表盘（React 页，可从 `/path-profile` 跳转）

### 3.1 课程上下文

多数功能都依赖 **当前课程**。切换课程的方式：

- 在 `/knowledge`、`/assistant` 等页面顶部的 **课程下拉框** 选择
- 从 `/courses` 点击某门课程卡片，会跳转到 `/knowledge?course_id=xxx`
- 系统会记住你最近使用的课程（`localStorage`）

**重要**：提问、生成 Wiki、做练习前，请确认顶部选中的课程正确。

### 3.2 页面技术说明（给队友）

- `/`、`/assistant`、`/evolution` 是 **React 页面**
- `/home`、`/courses`、`/knowledge`、`/practice`、`/dashboard`、`/path-profile` 主要是 **Stitch 静态页 + 真实 API**，视觉是设计稿风格，数据来自后端
- 若某块区域看起来像「占位文案」，但 Network 里 API 返回了数据，刷新或重新登录即可

## 4. 完整学习闭环（推荐顺序）

第一次使用或答辩演示，建议按以下顺序操作：

```text
① 登录（或注册）
② 进入课程空间 → 选择/创建课程
③ 知识库：上传资料 → 解析 → 切片 → 向量化 → 抽取知识点 → 生成 Wiki
④ AI 助手：提问、生成资源、（可选）沉浸课堂
⑤ 练习：生成题目 → 提交答案 → 查看错题
⑥ 诊断：生成/刷新学习诊断报告
⑦ 路径与画像：查看画像、记忆、学习路径、自进化策略
⑧ 仪表盘/首页：查看学习时长、掌握度、推荐
```

若使用 **`stu_01` + 公有《数据结构》课**，可从 **步骤 ④** 开始，跳过上传资料。

## 5. 各页面详细说明

### 5.1 品牌首页 `/`

**何时使用**：未登录访问、向他人介绍产品。

**功能**：

- 展示智学工坊品牌与核心能力介绍
- 右上角 **登录 / 注册** 弹窗
- 登录后自动离开此页，进入 `/home`

**注意**：此页 **不显示** 桌宠「知知」。

---

### 5.2 学习首页 `/home`

**何时使用**：登录后的默认入口，快速了解学习状态。

**主要区域**：

| 区域 | 功能 | 操作 |
|------|------|------|
| 当前课程卡片 | 显示正在学习的课程 | 点击可进入课程知识库 |
| 快捷提问框 | 直接向 AI 提问 | 输入问题 → 点击发送 → 跳转 `/assistant` 并带上问题 |
| 学习分析 | **真实**本周/本月时长、掌握度、按日柱状图 | 切换统计周期（非静态假数据） |
| 练习与诊断入口 | 快捷进入练习页 | 点击卡片跳转 `/practice` |
| 学习路径摘要 | 当前路径进度 | 「查看全路径」「继续闯关」→ `/path-profile` |
| 外部资源推荐 | 拓展阅读链接 | 「换一批」刷新推荐 |
| Wiki / Agent 动态 | 最近知识库与智能体活动 | 只读摘要 |

**学习时长统计**：在 `/assistant`、`/knowledge`、`/practice` 等页面停留且有过交互时，系统会发送心跳累计时长（单次最多 60 秒）。

---

### 5.3 课程空间 `/courses`

**何时使用**：管理你的课程列表。

#### 创建课程

1. 点击 **「创建课程」**
2. 在弹窗中填写：
   - **课程名称**（必填，如「数据结构与算法」）
   - **课程代码**（可选，如 CS202）
   - **简介**（可选）
3. 点击 **「创建课程」** 提交
4. 创建成功后会出现在课程列表；点击卡片进入该课的 `/knowledge`

#### 编辑 / 归档

- 课程卡片上的 **编辑** 按钮：修改名称、简介等
- **归档** 按钮：将课程标记为归档（不再默认展示）
- **公有模板课程**（如系统预置的《数据结构》）为 **只读**：不可编辑、不可归档，所有人可访问学习

#### 导入示例数据

部分环境提供 **「导入示例数据」** 按钮，可快速创建体验课（视部署配置而定）。

#### 最近访问

页面下方展示最近打开过的课程，点击可快速回到知识库。

### 5.4 课程知识库 `/knowledge`

**何时使用**：管理课程资料、构建知识库、浏览 Wiki 与知识图谱。这是整个系统的 **数据基础**。

#### 顶部操作

- **课程下拉框**：切换当前课程（必选）
- **Tab 切换**：资料库 | 课程 Wiki | 图谱视图 | 质量报告

---

#### Tab 1：资料库

##### 上传资料

1. 点击 **「上传资料」**
2. 选择本地文件（支持常见文档格式，如 PDF、Word、Markdown、TXT 等）
3. 上传完成后，资料出现在左侧列表

##### 资料处理流水线（必须按顺序）

选中一份资料后，右侧会出现处理按钮。**标准流程**：

| 步骤 | 按钮 | 作用 |
|------|------|------|
| 1 | **解析** | 提取文档文本 |
| 2 | **切片** | 将长文档切成可检索的小块（chunk） |
| 3 | **向量化** | 为每个 chunk 生成向量，供 RAG 检索 |
| 4 | **抽取知识点** | 从资料中识别细粒度知识点并归一化 |
| 5 | **生成 Wiki** | 基于知识点生成 LLM Wiki 页面 |

**快捷方式**：点击 **「入库并生成 Wiki」** 可一键执行完整流水线（适合新上传的资料）。

##### 其他操作

| 按钮 | 作用 |
|------|------|
| **检索资料** | 在当前课程知识库中做 Hybrid RAG 检索，输入关键词查看相关切片 |
| 查看切片预览 | 右侧网格展示 chunk 内容与元数据 |
| 下载资料 | 下载原始上传文件 |

##### 公有课程限制

若当前是 **公有《数据结构》模板课**，资料为系统预置，**不可** 对其执行解析/切片/向量化等写入操作，但可以 **检索、浏览 Wiki 和图谱**。

---

#### Tab 2：课程 Wiki

展示当前课程下所有 **LLM Wiki 页面**。

**浏览 Wiki 列表**：

- 每个卡片显示标题、摘要、页面类型
- 点击卡片进入 **Wiki 详情**

**Wiki 详情页应关注**：

| 内容 | 说明 |
|------|------|
| 正文 | Markdown 结构化内容 |
| 摘要 | 页面概要 |
| 来源引用 | 绑定的资料 chunk / 知识点，可追溯 |
| 版本 | 每次生成/编辑都会产生新版本 |
| 关联知识点 | 与课程知识点的链接 |

**返回列表**：详情页顶部有 **「返回 Wiki 列表」**。

**手动创建 Wiki**（若有入口）：可通过 API 或资料上的「生成 Wiki」触发，一般用户走自动生成即可。

---

#### Tab 3：图谱视图

以 **力导向图** 展示 Wiki 页面与知识点之间的关系。

**操作**：

- 拖拽、缩放浏览图谱
- 点击节点：右侧显示节点详情
- 若节点是 Wiki 页面，可 **「打开 Wiki 详情 →」**
- 公有知识邻居节点可能标注为只读参考

**适用场景**：答辩时展示「个人学习知识图谱」、查看知识点 prerequisite / similar 等关系。

---

#### Tab 4：质量报告

针对 **GraphRAG-ready** 课程（如公有《数据结构》）展示知识库质量指标：

- 资料数、chunk 数、向量数、知识点数
- 抽取/归一化统计（候选、合并、拒绝、保留）
- 检索质量抽样

适合向评委说明「知识库不是空的，且有工程化质检」。

### 5.5 AI 学习助手 `/assistant`

**何时使用**：课程答疑、智能体任务、个性化资源生成、沉浸课堂。这是 **React 全功能页**，体验最完整。

> **前置条件**：智能体模式依赖后台 **arq Worker**；若线上 Agent 任务一直 pending，请联系部署负责人确认 Worker 已启动。

#### 页面布局

```text
┌─────────────────────────────────────┬──────────────────┐
│  对话区（消息 + Agent 步骤时间线）      │  资源侧栏         │
│                                     │  （生成的资源产物） │
├─────────────────────────────────────┤                  │
│  输入框 + 发送                        │                  │
└─────────────────────────────────────┴──────────────────┘
```

#### 顶部控制栏

| 控件 | 说明 |
|------|------|
| **会话历史**（悬停/点击） | 查看当前课程的历史 Agent 会话；可切换会话或 **新建会话** |
| **课程下拉** | 选择答疑所属课程（必选） |
| **Wiki 章节**（可选） | 限定在某个 Wiki 页面上下文中回答 |
| **模式切换** | 「快速回答」 / 「智能体模式」 |
| **资料库** 复选框 | 是否启用 RAG 检索课程资料（建议勾选） |
| **Wiki** 复选框 | 是否结合 Wiki 内容 |

#### 两种模式对比

| | 快速回答 | 智能体模式 |
|---|---------|-----------|
| **适用** | 单轮答疑、概念解释 | 多步任务、资源生成、复杂规划 |
| **响应** | Tutor SSE 流式输出 | LangGraph Agent 动态规划 + 工具调用 |
| **可见过程** | 简单进度提示 | 可展开步骤时间线（规划/工具/观察/Review） |
| **后台** | 直接调 Tutor | 需 arq Worker 执行任务 |
| **产物** |  mainly 文字回答 + 引用 | 文字 + 资源 + 语音 + 视频 + 课堂等 |

**规则**：若你在「快速回答」下勾选了 **仅智能体可用的工具**（如生成资源、沉浸课堂、语音等），系统会自动切换到智能体模式。

#### 工具 Chip（智能体模式下）

输入框上方有一排可点击的工具标签，用于 **提示 Agent 优先使用某能力**（`tool_hints`）：

| 工具 | 典型用法示例 |
|------|-------------|
| 搜索知识库 | 「在资料里找关于红黑树的定义」 |
| 生成练习 | 「给我出 3 道二叉树单选题」 |
| 生成资源 | 「生成一份栈的复习总结」 |
| 更新画像 | 「我是计算机大二，想重点攻克图论」（对话式画像） |
| 课程答疑 | 「栈和队列有什么区别？请引用课程资料」 |
| 语音讲解 | 「用语音读一遍这段解释」 |
| 快速讲解视频 | 「生成一个短视频讲解 BFS」 |
| 沉浸课堂 | 「为广度优先搜索生成个性化沉浸课堂」 |

也可 **不用点 Chip**，直接用自然语言描述需求，Agent 会自动选工具。

#### 发送消息

1. 在底部输入框输入问题（`Enter` 发送，`Shift+Enter` 换行）
2. 点击 **发送**
3. 等待流式输出

**快速模式**：回答直接以 Markdown 显示，可点击 **查看详情** 看引用来源。

**智能体模式**：

- 执行过程中显示 **状态行**（如「正在检索资料…」「正在生成资源…」）
- 点击消息块可 **展开/折叠** 步骤时间线
- 工具完成后，产物出现在 **右侧资源侧栏**
- 支持 **内联语音播放**（TTS 生成时）

#### Agent 任务控制

| 操作 | 何时使用 |
|------|----------|
| **暂停接收 / 恢复查看** | 离开页面后回来，可恢复订阅 SSE 继续看进度 |
| **取消任务** | 终止当前 Agent 执行 |
| **新建会话** | 清空当前对话，开始新话题（后台旧任务可能仍在跑） |
| **确认/拒绝**（interrupt） | 高风险工具（如需人工确认的操作）会弹出确认 |

切换页面时，当前页面的 SSE 监听会停止，但 **后台 Agent 任务可继续**；返回后点「恢复查看」即可。

#### 可生成的资源类型

通过对话或工具，系统支持多种 **个性化学习资源**（在右侧资源侧栏查看）：

| 类型 | 说明 |
|------|------|
| 讲解 / 总结 / 例题 | 文字类 Markdown 资源 |
| 复习卡 / 错题解析 | 闪卡、错题巩固 |
| 图片 / 思维导图 / 图解 | 有文生图 API 时生成插图；无 API 时降级为 Mermaid 知识卡片 |
| 讲解视频 / 动画演示 | 视频类 job，异步生成 |
| 互动课件 | HTML 多页互动 PPT |
| **沉浸课堂** | OpenMAIC 个性化场景课堂，可启动播放 |
| 代码实操 / 拓展阅读 | 编程练习包、阅读清单 |
| 语音讲解 | TTS，对话区内联播放 |

**保存到 Wiki**：部分资源支持「保存到 Wiki」（视资源类型与界面入口而定）。

#### OpenMAIC 沉浸课堂（重点演示功能）

**触发方式**（智能体模式）：

```text
为【知识点名称】生成一个个性化沉浸课堂
```

**流程**：

1. Agent 基于课程 RAG、学生画像、薄弱点生成个性化 brief
2. 后台创建 `immersive_classroom` 任务
3. 完成后对话区出现 **课堂卡片**，点击可启动播放
4. 可继续异步 **导出 MP4**（带配音与烧录字幕）

**注意**：完整真实生成耗时较长，依赖 OpenMAIC 服务与模型配置；无 Key 时不会伪装成真实效果。

#### 联网搜索（可选）

Agent 在需要时可调用 **联网搜索** 工具补充最新资料，结果会标注为外部来源。是否触发取决于问题与 Agent 规划。

#### 示例提问

```text
# 快速答疑
栈和队列的时间复杂度分别是多少？请引用课程资料。

# 智能体 + 资源
帮我生成一份关于「二叉搜索树」的 Markdown 复习总结，包含定义、操作和复杂度。

# 智能体 + 练习
根据我最近在聊的「图遍历」，给我出 5 道中等难度的单选题。

# 对话式画像
我是软件工程大三学生，这门课想重点突破树和图，解释请偏直觉一点。

# 沉浸课堂
为「广度优先搜索」生成一个个性化沉浸课堂。
```

### 5.6 练习与诊断 `/practice`

**何时 use**：巩固知识、查看错题、获取学习诊断。

#### Tab：练习生成

##### 配置题目

| 选项 | 说明 |
|------|------|
| **题型** | 单选、多选、判断、简答、填空、编程 |
| **难度** | 入门 / 进阶 / 挑战（系统也会根据画像自适应推荐难度） |
| **知识点/主题** | 下拉选择或手动输入，如「栈与队列」「二叉树」 |
| **题目数量** | 根据界面输入（通常 1～10 道） |

##### 生成与答题

1. 点击 **「生成练习」**（右下角浮动按钮也可触发）
2. 系统生成题目列表，逐题作答
3. 选择选项 / 填写答案后，点击 **「提交答案」**
4. 查看 **对错、解析、得分**
5. **上一题 / 下一题** 切换；完成后可 **存入错题本**

##### 助手推荐练习

若你最近在 `/assistant` 讨论过某些知识点，页面可能展示 **「根据最近提问推荐」** 的快捷生成入口（`practice_from_chat` 类型推荐），一键出题。

##### 答题竞技

Tab 存在，部分为展示/扩展入口，核心功能以「练习生成」为主。

#### Tab：错题本

- 列出答错的题目
- 可重新练习、查看解析
- 错题会影响后续 **诊断** 和 **画像**

#### Tab：诊断报告

**生成诊断**：

1. 切换到 **「诊断报告」** Tab
2. 点击 **「生成/刷新诊断」**（具体按钮文案以页面为准）
3. 等待系统分析你的练习记录、错题、掌握度

**诊断内容通常包括**：

- 薄弱知识点列表
- 常见错误模式
- 学习建议与下一步推荐
- 与 Wiki / 练习的关联

诊断完成后会触发 **EventBus 后置流程**（如自进化分析、记忆反思），可在 `/path-profile` 看到变化。

### 5.8 学习路径与画像 `/path-profile`

**何时 use**：理解「系统为什么这样推荐我」、管理长期记忆、规划学习路径、处理自进化策略。

页面通常分为多个区块（滚动浏览）：

---

#### 学生画像

| 内容 | 说明 |
|------|------|
| 全局画像 | 跨课程的学习特征、偏好摘要 |
| 课程画像 | 当前选中课程的掌握度、薄弱点 |
| 对话式画像证据 | 你在 `/assistant` 说过的专业、年级、目标等，被 Agent 提取并记录 |
| **重建画像** | 点击后触发 Profile Agent 重新汇总（耗时，勿频繁点击） |

**区分**：全局 vs 课程级 — 掌握度写入 **课程画像**，不会覆盖其他课。

---

#### 长期记忆

| 操作 | 说明 |
|------|------|
| 查看列表 | 活跃 / 归档 / 全部 切换 |
| **Memory 反思** | 手动触发 Memory Agent 从近期行为提取记忆 |
| 查看证据 | 点击链接图标看记忆来源 |
| 归档 | 不再使用的记忆可归档（非删除） |
| 恢复 | 已归档记忆可恢复 |

**限制**：每门课最多 **20 条** 活跃记忆，全局最多 **10 条**；超出会自动归档旧记录。

---

#### 自进化策略（区块 + 独立页）

**在 `/path-profile` 内**：

| 操作 | 说明 |
|------|------|
| **触发分析** | 运行 Evolution Agent，基于诊断/练习/画像生成策略建议 |
| **刷新** | 重新加载策略列表 |
| **确认** | 对 `draft` 状态且 risk=medium/high 的策略人工确认后生效 |
| **拒绝** | 拒绝不合适的策略 |
| **回滚** | 对已生效策略恢复到上一版本 |

**策略类型示例**：答疑风格、资源生成策略、难度调节、推荐策略、学习路径等。

每条策略包含：

- `before_snapshot` / `after_snapshot`（变更前后）
- `change_summary`（变更摘要）
- `evidence`（证据）
- `risk_level`（low / medium / high）
- `status`（draft / active / superseded / rolled_back / rejected）

## 8. Mock 模式与真实大模型

| 模式 | 何时 | 表现 |
|------|------|------|
| **Mock** | 服务器未配置 LLM API Key | 全流程可跑通，返回结构化占位内容，适合功能演示 |
| **真实模型** | 配置了 OpenAI-compatible Provider（如 MiMo） | 回答质量、资源生成、Agent 规划为真实效果 |

**答辩注意**：

1. 明确当前环境是 Mock 还是真实模型，**不要混讲**
2. Mock 内容仍与《数据结构》场景相关，不是简单 `mock response`
3. 沉浸课堂、视频导出等重任务在 Mock 下可能有降级或较长等待

## 9. 常见问题与排查

### 9.1 页面显示占位数据（如「高等数学」「24 文档」）

**原因**：未登录、Token 过期、或 API 地址错误。

**处理**：

1. 退出重新登录
2. 确认浏览器 Network 请求指向正确 API（线上应为同域 `/api/v1`）
3. 清除 `localStorage` 中的 `zhixue_api_base` 后刷新
4. 确认后端 `/health` 正常

---

### 9.2 上传资料后搜不到 / 答疑无引用

**原因**：未完成处理流水线。

**处理**：回到 `/knowledge` → 选中资料 → 依次 **解析 → 切片 → 向量化**（或点「入库并生成 Wiki」）。

---

### 9.3 AI 助手智能体任务一直转圈

**可能原因**：

1. **arq Worker 未启动**（最常见）
2. Redis 连接失败
3. 任务执行超时

**处理**：联系部署负责人检查 Worker 进程；刷新页面后点 **「恢复查看」**；必要时 **取消任务** 重试。

---

### 9.4 沉浸课堂 / 视频生成失败

**可能原因**：OpenMAIC 服务未启动、模型 Key 缺失、生成超时。

**处理**：确认部署文档中 OpenMAIC 端口（通常 3001）已启动；无 Key 时使用 Mock 降级说明，答辩时如实告知。

---

### 9.5 切换课程后数据不对

**处理**：确认页面顶部 **课程下拉框** 与预期一致；URL 中 `course_id` 参数是否正确。

---

### 9.6 登录后跳转到空白页

**处理**：尝试直接访问 `/home`；检查浏览器控制台是否有 JS 错误；换 Chrome/Edge 最新版。

---

### 9.7 侧边栏在手机上不见了

**说明**：侧边栏在 **md 及以上屏幕** 显示；小屏请通过页面内链接或地址栏直接跳转路由。
