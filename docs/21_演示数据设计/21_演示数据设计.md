## 演示课程

默认演示课程为《数据结构》，建议覆盖线性表、栈与队列、树、图、查找和排序，形成足够清晰的知识关系与难度梯度。

## 演示账号与资料

演示账号应使用虚构学生数据，不提交真实隐私或固定密码。资料应放在 `data/seed_knowledge/data_structure`，包含可解析文本/PDF、明确章节和来源信息。

## 演示场景数据

- Wiki：展示来源、版本、关系和 AI 推断提示。
- Tutor：准备可被资料回答的问题与需要澄清的问题。
- 练习：包含正确与错误作答，能触发薄弱点诊断。
- 对话式画像：准备“专业、年级、目标、偏好、薄弱点、错误模式”自然语言输入，例如“我是软件工程大二学生，递归和二叉树遍历薄弱，喜欢 Python 代码示例和分步骤讲解”。
- 自进化：准备可解释的策略前后变化与回滚演示。
- Agent：保留一条完整调用链用于答辩说明。

管理员后台当前未实现，因此不设计管理员后台演示数据。

## 初始化与验收

当前仍缺少一键初始化完整演示数据能力。实现时必须可重复执行、避免覆盖用户数据，并在初始化后运行真实主链路和浏览器演示点检。

Phase 3.1 稳定演示已提供两类脚本：

```powershell
scripts/start_phase31_demo.ps1
python scripts/agent_demo_check.py --base-url http://127.0.0.1:8000/api/v1
```

`agent_demo_check.py` 会创建隔离演示账号和课程，发送两轮 Agent 消息：

1. 对话式画像更新：验证 `update_profile_from_dialogue` 工具、画像证据和 `/path-profile` 展示数据。
2. 学习路径生成：验证 MiMo Supervisor、Tool Registry、arq Worker、事件流和最终消息持久化。

这不是完整种子数据初始化脚本，但可作为 Phase 3.1/Phase 4 的稳定冒烟验收入口。
