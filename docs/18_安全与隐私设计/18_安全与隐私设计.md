## 认证与隔离

业务 API 使用 JWT Bearer Token。涉及用户、课程、Wiki、练习、诊断、画像、记忆和策略的查询必须绑定当前用户并校验课程归属。前端传入的 `user_id` 不可信。

## 文件和模型安全

上传文件保存到本地存储，解析流程应限制类型和大小并记录失败状态。所有 LLM 调用通过 Provider；API Key 仅存在环境变量，不进入日志、文档或仓库。

## 内容与日志安全

- AI 输出尽量基于资料和 Wiki，并返回引用。
- 无依据内容明确标记 AI 推断。
- 关键生成内容经过 Review Agent 或规则校验。
- LLM 日志脱敏保存 provider、model、token、latency、status，不保存密钥。

## 删除和缺口

长期记忆支持删除；自进化策略支持回滚且不删除历史。完整用户数据导出、统一软删除策略、文件病毒扫描和更细粒度管理员审计仍是后续工作。
