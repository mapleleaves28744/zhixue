## 材料清单

比赛提交材料应包含作品说明书、技术报告、部署与使用说明、演示视频、答辩材料、源代码、数据库迁移与必要支撑截图。最终以赛题官方通知为准。

## 作品说明与技术报告

作品说明书突出学生问题、产品闭环和使用方式；技术报告说明系统架构、数据模型、LLM Provider、RAG、Agent、自进化、安全和测试。两者都必须区分当前实现与后续规划。

## 创新与完成度证据

重点证据包括真实 LLM 主链路验收、Wiki 来源与版本、自进化策略证据/风险/回滚、Agent run 日志、权限隔离测试、Next 安全升级和构建结果。截图应来自当前版本，不使用概念图冒充实现。

## 里程碑

1. 完成演示数据与浏览器 E2E。
2. 强化 Wiki、Agent、自进化的前端可见性。
3. 完成 Docker Compose 和演示环境验收。
4. 冻结功能后录制视频、整理报告和准备答辩。
