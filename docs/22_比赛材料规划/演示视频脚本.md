## 录制前准备

1. 固定演示账号与《数据结构》课程（或已入库公有模板）。
2. 确认 LLM 模式：真实模型需标注 provider；Mock 模式需口播说明「演示模式」。
3. 启动环境：`scripts/start_phase31_demo.ps1` 或手动启动 backend + Worker + frontend。
4. 清理浏览器无关标签；关闭开发者工具（除非展示 Agent 事件）。
5. 准备口播提纲：问题定位 → 闭环演示 → 三大创新 → 工程落地。

## 时间轴脚本 0:00–7:00

### 0:00–0:30 开场：问题与定位

**画面**：品牌首页 `/` → 登录

**口播**：
> 高校学生面临资料分散、AI 问答一次性、推荐缺依据等问题。智学工坊是面向课程学习的多智能体个性化空间，把资料变成有来源的 LLM Wiki，并通过 Agent 协作完成答疑、资源、练习、诊断与策略更新。

**强调**：不是普通聊天机器人。

---

### 0:30–1:30 建课与资料流水线

**画面**：`/courses` 创建课程 → `/knowledge` 上传资料

**操作**：
1. 展示课程列表，创建或进入《数据结构》。
2. 上传一份资料（或展示已入库 32 份资料）。
3. 依次展示：解析 → 切片 → 向量化 → 知识点抽取。

**口播**：
> 资料进入系统后，自动完成解析、切片和向量化，形成可检索的课程知识库。公有数据结构知识库已入库 1608 个 chunk 和 125 个知识点。

**截图路由**：`/knowledge`

---

### 1:30–2:30 LLM Wiki：来源与版本

**画面**：`/knowledge` Wiki 列表 → Wiki 详情

**操作**：
1. 打开 Wiki 页面，展示摘要与正文。
2. 点开**来源追溯**和**版本历史**。
3. 如有关系链接，展示知识点关联。

**口播**：
> LLM Wiki 不是普通笔记。每个页面有来源、版本和关系，AI 推断内容会明确标注，支持回滚。

**创新镜头**：对比「普通 RAG 问答」vs「可沉淀 Wiki」。

---

### 2:30–4:00 AI 助手：Tutor + 智能体 + 资源

**画面**：`/assistant`

**操作**：
1. **快速模式**：提问「栈和队列的区别，引用课程资料」→ 展示流式回答与引用。
2. 切换到**智能体模式**，输入「帮我生成二叉树前序遍历的讲解和练习题」。
3. 展开**步骤时间线**，指出 tool chip（检索、资源、练习等）。
4. 打开**资源侧栏**，展示生成的讲解、思维导图或闪卡。
5. （可选）展示内联语音播放。

**口播**：
> 助手页已 React 化。快速模式适合即时答疑；智能体模式由 LangGraph Supervisor 动态选工具，全过程可见。20 条 Agent 场景评测全部通过。

**截图路由**：`/assistant`（对话区、时间线、资源侧栏）

---

### 4:00–4:45 OpenMAIC 沉浸课堂

**画面**：`/assistant` 智能体模式

**操作**：
1. 输入：「为广度优先搜索生成一个个性化沉浸课堂」。
2. 展示任务进度卡片。
3. 完成后展示课堂卡片；如有 MP4，播放片段（5–10 秒）。

**口播**：
> 基于课程 RAG 和学生画像，一句话生成个性化沉浸课堂，并异步导出带配音字幕的 MP4。课堂播放采用短期签名，保证安全隔离。

**截图路由**：`/assistant`（课堂卡片、MP4 产物）

---

### 4:45–5:30 练习与诊断

**画面**：`/practice`

**操作**：
1. 生成或打开练习题。
2. 故意答错 1–2 题并提交。
3. 查看错题本与诊断报告（薄弱点、建议动作）。

**口播**：
> 练习结果进入诊断，薄弱点和错误模式会更新画像，并影响后续推荐和路径。

---

### 5:30–6:30 画像、记忆与自进化

**画面**：`/path-profile` → `/evolution`

**操作**：
1. 展示全局画像与课程画像、对话证据。
2. 展示长期记忆（活跃/归档切换、20 条容量提示）。
3. 展示学习路径与推荐。
4. 跳转 `/evolution`，展示策略列表、证据、风险等级；演示回滚（或说明可回滚）。

**口播**：
> 自进化不修改代码，只更新学习策略。每次变更有证据、风险等级和版本链，支持回滚。

**创新镜头**：策略 diff 或版本号。

---

### 6:30–7:00 总结：闭环与工程

**画面**：`/home` 学习分析 或回到 `/`

**口播**：
> 从资料上传到策略更新，智学工坊形成完整学习闭环。后端 304 项测试通过，真实 LLM 主链路 23 步验收，Next.js 16 安全升级。感谢观看。

**可选画面**：快速闪过 pytest 输出或 `local_check.ps1` 结果（3 秒）。

## 创新点镜头

| 镜头 | 展示内容 | 时长建议 |
|---|---|---|
| LLM Wiki | 来源标签 + 版本列表 | 15s |
| 可观察 Agent | 步骤时间线 + tool chip | 20s |
| 受控自进化 | 策略证据 + 回滚按钮 | 15s |
| 多模态 | 资源侧栏 + MP4/语音 | 20s |
| 真实数据 | `/home` 学习分析柱状图 | 10s |

**不要出现**：管理员后台、教师端（当前未实现）。

## 录制约束

1. 每个 AI 输出尽量展示**依据、来源或引用**。
2. 网络失败时使用已验证本地环境，不用假结果冒充真实调用。
3. 无 API Key 时口播说明 Mock 演示模式。
4. 清理 Token、API Key、个人隐私。
5. 固定分辨率（建议 1920×1080），帧率 30fps。
6. 导出格式：MP4，H.264，≤500MB（按赛题平台要求调整）。
