# 录制前智能问答与产物准备清单

## 目录导读

> 文档状态：**2026-07-13 演示录制执行清单**
>
> 用途：在录屏前完成耗时的智能问答、资源和课堂任务，录制时只展示真实提交状态与已经完成的对应产物。
>
> 配套脚本：[`演示视频脚本.md`](演示视频脚本.md)

本清单只使用当前已实现的学生端能力。每项产物都要先人工检查课程、来源、题目、用户隐私和 Provider 状态；若未成功，录屏时跳过该段，不用截图或手工编造内容替代。

## 一、准备原则

1. 使用同一个演示账号和同一门《数据结构》课程，保证问答、画像、练习和策略能相互关联。
2. 先准备资料和 Wiki，再提问，再生成练习/课堂，最后查看画像、诊断与策略；这样系统才有真实的上下文和行为证据。
3. 每次长任务都记录“提交中”画面和完成后的会话/产物链接；正式录制可剪掉等待，但必须注明“异步任务完成记录”。
4. 快速问答只用于展示有引用的即时回答；多步骤资源、课件和沉浸课堂使用智能体模式。不要把沉浸课堂放在快速问答中请求。
5. 如果本次使用 Mock Provider，所有对应产物都需在视频里按 Mock 演示口径说明；不要与历史真实 Provider 截图混用。

## 二、推荐执行顺序

| 顺序 | 页面 | 动作 | 目的 |
|---:|---|---|---|
| 1 | `/knowledge` | 打开一份已处理资料与一页带来源的 Wiki | 确认知识库证据可用 |
| 2 | `/assistant` 快速模式 | 完成 Q1、Q2 | 准备引用问答与追问建议 |
| 3 | `/assistant` 智能体模式 | 完成 A1、R1～R8 | 准备受控工具时间线和个性化资源包 |
| 4 | `/practice` | 完成 P1，故意错一题；打开已有诊断 | 形成错题、诊断、推荐证据 |
| 5 | `/assistant` 智能体模式 | 完成 A3 | 准备沉浸课堂与 MP4（长任务） |
| 6 | `/path-profile`、`/evolution` | 完成 U1 后检查画像证据、记忆、路径和策略 | 准备个性化与可控自进化画面 |

## 三、直接复制的提问清单

### Q1：可信资料问答（视频 1:25–2:20）

**页面/模式**：`/assistant`，快速模式，选中《数据结构》课程。

**输入**：

```text
为什么栈适合做括号匹配？请只基于当前课程资料回答：说明左括号、右括号分别如何处理，并给出引用。
```

**录制前确认**：

- 回答中至少有一条可展开的 S1/S2 真实来源引用；展开后能看到资料标题或片段。
- 回答包含“左括号入栈、右括号匹配栈顶、不匹配或栈空时失败、结束后栈应为空”中的主要逻辑。
- 没有把通用知识伪装成课程资料。若引用不足，改用课程中实际覆盖的“栈/括号匹配”内容，而不是强行录制。

**录制保留**：问题提交、首个流式字、展开的一条引用、追问建议（如有）。

### Q2：追问与知识关联（可作为 Q1 的补镜）

**页面/模式**：`/assistant`，快速模式，在 Q1 同一会话中提问。

**输入**：

```text
如果读到右括号时栈为空，为什么可以立即判定表达式不匹配？请结合刚才引用的资料，用一个最小例子说明。
```

**录制前确认**：回答仍有依据或明确说明依据不足；例子简短、没有与 Q1 自相矛盾。

**录制用途**：只在 Q1 的回答不够完整时作为补镜，不必占用正式旁白时长。

### A1：智能体分步讲解与练习（视频 2:20–3:30）

**页面/模式**：`/assistant`，智能体模式，选中《数据结构》课程。

**输入**：

```text
基于当前课程资料，为二叉树的前序、中序和后序遍历生成分步骤讲解，并附三道由易到难的练习题。每一步说明访问顺序，练习题给出答案和简短解析。
```

**录制前确认**：

- 会话时间线出现检索、工具执行/观察、Review 或等价运行步骤，且最终状态成功。
- 产物同时包含三种遍历的访问顺序、分步讲解、三道递进练习、答案/解析。
- 课程资料引用或依据状态可见；若实际课内知识点名称不同，以系统显示为准。

**录制保留**：新建同类请求的真实 queued/running 画面；已完成会话中的一条步骤时间线、一次工具详情、Review 和练习产物。两段画面均标注“异步任务完成记录”。

### A2：可选资源产物（智能体亮点备选）

**页面/模式**：`/assistant`，智能体模式。

**输入（二选一）**：

```text
基于当前课程资料，生成一份二叉树遍历的互动课件，包含前序、中序、后序遍历的对比、一个例子和两道随堂练习。
```

```text
基于当前课程资料，为队列的基本操作生成一张层级清晰的思维导图，并说明每个节点的学习重点。
```

**录制前确认**：对应课件或导图产物可以打开，且主题与课程资料相符。

**录制用途**：只在 A1 的右侧产物不够直观时插入 3–5 秒；不要在七分钟主片中同时展示两个资源。

### 个性化资源包：使用同一份学习偏好生成多种资源

**统一前提**：先完成 U1，使系统有“数据结构期末复习、二叉树/图遍历优先、分步骤讲解、先例子后练习”的对话画像或学习偏好证据。以下请求均在 `/assistant` 智能体模式中完成，并选中同一门《数据结构》课程。

**展示原则**：七分钟主片只选 **两项** 最稳定、最直观的资源展示，推荐 `R1 闪卡 + R4 互动课件`；其余资源作为答辩备份。不要在一个请求中同时要求多种资源，否则工具时间线变长、失败定位困难、画面也不聚焦。

### R1：个性化闪卡包（优先展示）

**输入**：

```text
基于当前课程资料，并按照我“先看例子、再分步骤练习”的偏好，为二叉树遍历生成 12 张复习闪卡。每张卡片正面只放一个问题，背面给出简短答案、一个记忆提示和对应的知识点；覆盖前序、中序、后序和层序遍历的区别。
```

**个性化点**：同一主题被拆为低负担、可连续复习的问答卡，适合考前碎片时间；提示词中明确了学生偏好与覆盖范围。

**录制前确认**：卡片数接近 12；正反面信息清晰，至少覆盖四种遍历；不出现脱离课程主题的大段泛化内容。

**录制用途**：推荐保留。展示一张正面、一张翻转后的背面即可，用于证明“资源不是一份通用长文本”。

### R2：从错题生成针对性解析与变式例题

**前置**：先完成 P1，确认有一条真实的二叉树遍历错题记录。

**输入**：

```text
针对我刚才在二叉树遍历中答错的问题，结合当前课程资料，先用分步骤方式解释错误原因，再生成两道同一易错点的变式例题。每题给出答案、解析和常见误区提示；难度从基础到中等。
```

**个性化点**：资源由真实错题和错误模式触发，而不是仅由知识点标题触发。

**录制前确认**：解析能对应实际错题；两道变式题与原题的易错点有关联；答案与解析齐全。

**录制用途**：适合答辩备份，或替代普通练习段中的一张静态题卡。

### R3：考前分层复习摘要

**输入**：

```text
基于当前课程资料、我的期末复习目标和“先例子后练习”的偏好，为二叉树遍历生成一份 10 分钟复习摘要。按“核心概念—一个最小例子—易错点—30 秒自测”四个小节组织，并标出我应优先复习的内容。
```

**个性化点**：同一知识点按学生的复习时间、目标和学习顺序压缩，而不是生成百科式总结。

**录制前确认**：四个小节齐全；自测题答案可核对；“优先复习”能与画像或诊断中的薄弱点一致。

**录制用途**：可作为 `/path-profile` 路径与推荐的补镜，不建议单独占用主片时间。

### R4：可交互遍历课件（优先展示）

**输入**：

```text
基于当前课程资料和我偏好分步骤讲解的学习方式，生成一份二叉树遍历互动课件。使用逐步演示形式：先展示一棵小型二叉树，再分别按前序、中序、后序高亮访问顺序，最后加入两道随堂练习。面向本科生期末复习，避免大段文字。
```

**个性化点**：把“分步骤、先看例子”的偏好落实为逐步演示和小树例子，而非只在标题中写“个性化”。

**录制前确认**：课件可以打开并翻页；包含小型二叉树、三种遍历对比和两道练习；不要把 HTML 互动课件称为讲解视频。

**录制用途**：推荐保留。主片可在 Agent 段右侧产物中展示 3–5 秒，或作为答辩时的展开演示。

### R5：知识结构思维导图

**输入**：

```text
基于当前课程资料，为“二叉树遍历”生成一张三层思维导图：第一层区分四种遍历，第二层写访问规则，第三层写典型应用或易错点。我的目标是期末复习，请突出容易混淆的前序、中序、后序差异。
```

**个性化点**：围绕学生的“容易混淆”和期末复习目标组织知识层级。

**录制前确认**：导图层级不超过三层、文字可读；四种遍历与访问规则无明显混淆。

**录制用途**：适合作为 R4 的替代方案，画面更静态但稳定；不要和 R4 同时放入主片。

### R6：队列保障 BFS 层序访问的流程图

**输入**：

```text
请基于当前课程资料，为广度优先搜索生成一张流程图，清楚展示“起点入队—队首出队—访问邻接点—未访问节点入队—队列为空结束”的顺序。面向刚开始学习图遍历的学生，重点标出队列为什么能保证按层访问。
```

**个性化点**：针对“先例子、分步骤”的偏好，把抽象算法转为单条可跟随的流程。

**录制前确认**：流程图能清晰读出入队/出队循环；没有把 DFS 的栈逻辑混入其中。

**录制用途**：适合与 A3 沉浸课堂主题保持一致，作为课堂前的 2 秒补镜或答辩备份。

### R7：个性化教学卡片/概念图

**输入**：

```text
基于当前课程资料和我偏好先看例子的学习方式，为“二叉树中序遍历”生成一张教学知识卡片：包含一棵小型树、访问顺序、一个记忆口诀和一个易错提醒。采用清晰、低干扰的教育科技风格，适合本科生期末复习。
```

**个性化点**：用可视化小例子、口诀和易错提醒降低首次理解门槛。

**录制前确认**：图片/卡片可打开；文字没有被裁切或出现乱码；若当前环境降级为 Mermaid 卡片，按“结构化演示卡片”展示，不能说成真实文生图效果。

**录制用途**：适合答辩备份；主片中仅在视觉素材不足时使用。

### R8：个性化音频讲解与视频分镜（长任务备选）

**音频输入**：

```text
请把“二叉树中序遍历的核心规则、一个小例子和常见误区”生成一段 90 秒以内的中文复习音频讲解。面向正在期末复习、喜欢分步骤学习的本科生，语速适中，结尾给出一道自测题。
```

**分镜输入**：

```text
基于当前课程资料，为“广度优先搜索为什么使用队列”生成一个 60 秒的 HTML 分镜讲解页。按“问题—小图示例—队列逐步变化—总结自测”组织，面向先看例子再练习的本科生。
```

**录制前确认**：音频可播放，或 HTML 分镜能在页面预览；主题、时长与学生层级相符。若准备短讲解 MP4，需明确说“视频/短视频”，并把它与互动课件区分开。

**录制用途**：只作为多模态能力的答辩备份。七分钟主片已有沉浸课堂与 MP4 时，不再加入这两项，以免重复占用时长。

### R9：基于画像的分层练习组

**输入**：

```text
根据我的期末复习目标、二叉树遍历薄弱点和“先例子后练习”的偏好，生成 6 道二叉树遍历练习：2 道基础识别题、2 道步骤推演题、2 道综合应用题。每题标注难度、考查点、答案和解析；先给一道带例子的引导题。
```

**个性化点**：难度、题型顺序和引导方式都由学生目标、薄弱点与偏好决定。

**录制前确认**：题目总数为 6，难度分层明确；每题有答案/解析；与 P1 的错题主题可以形成递进关系。

**录制用途**：适合替换 P1 的既有练习，或在答辩时解释“个性化不只是换一段文案”。

### P1：练习、错题与诊断（视频 4:10–5:00）

**页面/模式**：先完成 A1，然后在 `/practice` 打开与二叉树遍历关联的练习。

**操作**：故意将一道确定答案的题答错；提交后打开错题/解析。若要补充诊断证据，使用已存在的诊断入口生成或打开最近一份报告。

**建议作答策略**：选择“给定二叉树，写出中序遍历序列”这类有明确标准答案的题；不要故意答错开放题，以免评分依据不稳定。

**录制前确认**：错题记录含题目、学生答案、正确答案/解析、知识点或错误标签；诊断报告标有生成时间和至少一个可执行建议。

### A3：个性化沉浸课堂（视频 3:30–4:10）

**页面/模式**：`/assistant`，智能体模式。

**输入**：

```text
基于当前课程资料和我的分步骤讲解偏好，为广度优先搜索生成个性化沉浸课堂。请突出队列如何保证按层访问，并给出一个小型图遍历示例。
```

**录制前确认**：

- 出现真实课堂任务卡并进入完成状态；能打开课堂页面。
- 若本环境已完成 MP4 导出，视频可播放且含配音/字幕；否则只展示已完成课堂，不能声称已经导出视频。
- 课堂主题、课程、用户与任务记录相匹配。

**录制保留**：提交后任务卡、完成课堂卡片、约五秒的播放画面。每个完成画面标注“异步任务完成记录”。

### U1：对话式画像与个性化证据（视频 5:00–6:10）

**页面/模式**：`/assistant`，智能体模式；完成后前往 `/path-profile`。

**输入**：

```text
我是计算机专业大二学生，正在准备数据结构期末考试。我的目标是先掌握二叉树遍历和图遍历；我更喜欢分步骤讲解、先看例子再做题。请根据这些信息为我安排下一步学习建议。
```

**录制前确认**：

- `/path-profile` 可看到对应的对话画像证据或学习偏好，不展示敏感个人信息。
- 学习路径、推荐或课程画像中至少有一项能反映“二叉树/图遍历、分步骤、例子后练习”的上下文。
- 如没有自动产生新策略，展示已有且证据完整的策略详情；不要为录制强行触发高风险策略。

**录制保留**：对话证据、长期记忆来源、路径理由；在 `/evolution` 展示已有策略的证据、风险、版本和回滚入口。

## 四、录制前验收表

| 检查项 | 必须看到 | 不通过时处理 |
|---|---|---|
| Q1 | 真实资料引用可展开 | 换为课程资料明确覆盖的主题后重问 |
| A1 | 受控步骤时间线 + 讲解/练习产物 | 重试同一请求；仍失败则只展示可信问答，不伪造 Agent 成功 |
| P1 | 评分解析 + 错题 + 有时间的诊断 | 仅展示已完成诊断，旁白明确为历史记录 |
| A3 | 完成课堂；MP4 仅在真实可播放时展示 | 去掉 MP4 画面与对应口播，保留课堂完成记录 |
| U1 | 画像证据或偏好可见 | 不展示“对话式画像更新”断言，改为展示既有画像与策略证据 |
| Provider | 真实状态或 Mock 状态一致 | 统一更换为当前环境对应的口播与字幕 |
