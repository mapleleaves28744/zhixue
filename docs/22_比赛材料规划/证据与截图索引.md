## 2. 必拍截图清单

录屏或 PPT 制作时，按以下路由顺序拍摄，确保覆盖比赛核心功能。

| 序号 | 路由 | 必拍内容 | 用途 |
|---|---|---|---|
| 1 | `/` | 品牌首页、登录入口 | PPT 封面、项目定位 |
| 2 | `/home` | 学习分析（本周/本月时长、掌握度、柱状图） | 个性化闭环、真实数据 |
| 3 | `/courses` | 课程列表、创建课程 | 主链路起点 |
| 4 | `/knowledge` | 资料上传、解析状态、Wiki 列表 | 知识库构建 |
| 5 | `/knowledge`（详情） | Wiki 来源、版本历史 | LLM Wiki 创新点 |
| 6 | `/assistant` | 快速模式流式回答 + 引用 | Tutor 能力 |
| 7 | `/assistant` | 智能体模式、步骤时间线、tool chip | 多 Agent 可见性 |
| 8 | `/assistant` | 资源侧栏、多模态产物 | 资源生成 |
| 9 | `/assistant` | 历史课堂卡片、MP4（明确历史产物），或当前互动课件 | 资源与产品边界 |
| 10 | `/practice` | 练习提交、错题、诊断报告 | 练习闭环 |
| 11 | `/path-profile` | 画像、记忆、对话证据 | 个性化 |
| 12 | `/path-profile` | 学习路径、自进化策略 | 策略版本 |
| 13 | `/evolution` | 策略列表、回滚操作 | 自进化创新 |
| 14 | 全站 | 「知知」桌宠、提醒气泡（可选） | 用户体验 |

### 截图要求

1. 使用真实登录账号，不用静态占位页
2. 截图右下角可标注日期与路由
3. 敏感信息（API Key、Token）必须打码
4. Mock 模式截图需标注「演示模式」

## 3. 7 分钟视频时间轴

与 [演示视频脚本.md](演示视频脚本.md) 对齐。

| 时间 | 段落 | 页面 / 动作 | 强调点 |
|---|---|---|---|
| 0:00–0:30 | 开场 | `/` 登录 | 问题定位：资料分散、AI 一次性 |
| 0:30–1:20 | 课程与资料 | `/courses` → `/knowledge` | 已入库资料、解析、切片、向量化 |
| 1:20–2:10 | Wiki | `/knowledge` 详情 | 来源、版本、关系 |
| 2:10–3:50 | AI 助手 | `/assistant` | Tutor 引用 + 智能体任务 + 资源侧栏 |
| 3:50–4:30 | 连续对话与互动课件 | `/assistant` | 追问承接 + 已完成 HTML 课件；课堂仅可展示历史 |
| 4:30–5:20 | 练习诊断 | `/practice` | 出题、答错、诊断 |
| 5:20–6:30 | 画像与自进化 | `/path-profile` → `/evolution` | 记忆、策略、风险、回滚 |
| 6:30–7:00 | 总结 | `/home` 或回到 `/` | 闭环 + 工程落地 |
