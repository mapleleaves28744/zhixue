### 1.2.1 画像一：计算机专业本科生「考前冲刺者」小林

| 维度 | 描述 |
|---|---|
| 背景 | 大二，主修计算机，选修《数据结构》，期末考前两周 |
| 学习目标 | 快速补齐链表、树、图等薄弱章节，通过练习验证掌握度 |
| 痛点 | 课件分散、不知道先复习什么；通用 AI 容易编造、无课程依据 |
| 典型行为路径 | 创建课程 → 上传老师 PDF → `/knowledge` 解析切片 → RAG → `/assistant` Tutor → 生成练习 → `/practice` → 诊断与推荐 |
| 系统响应 | Hybrid RAG、自适应难度、`PracticeSuggestionService` 练习主题推荐 |
| 成功标准 | 30 分钟内完成「定位薄弱点 → 答疑 → 做题 → 看到诊断依据」闭环 |

**一周使用节奏（示例）：**

| 星期 | 行为 | 系统模块 |
|---|---|---|
| 周一 | 上传三章课件，触发 `parse_uploaded_document` | `/knowledge` |
| 周二 | 针对「二叉树」RAG 检索 + Tutor 追问 | `/assistant` 快速模式 |
| 周三 | 智能体生成 10 道题并提交 | `generate_quiz`、`/practice` |
| 周四 | 查看诊断，刷新推荐 | `/practice`、`/dashboard` |
| 周五 | 桌宠提醒完成路径节点 | `PetCompanion`、`/path-profile` |

**典型对话：**

> 小林：「红黑树插入旋转我总是搞混，结合我们课件讲一下，并出 5 道题。」
>
> 系统：`answer_course_question` 返回分步讲解与引用；`generate_quiz` 出题；完成后 `analyze_learning_diagnosis` 更新薄弱点。

### 1.2.3 画像三：自主学习研究生「深度溯源者」小周

## 1.3 赛题背景与新时代大学生需求

### 1.3.1 赛题定位

本项目对应**中国软件杯 A3 赛题**：基于大模型的个性化资源生成与学习多智能体系统开发。

当前演示课程为**《数据结构》**，公有知识库已入库 **32** 份资料、**1608** 个 chunks、**1608** 条真实 BGE embedding、**125** 个知识点。

### 1.3.2 需求矩阵

| 学生需求 | 具体表现 | 系统响应 |
|---|---|---|
| 碎片化学习 | 课后时间零散 | 资料解析、Hybrid RAG、Wiki |
| 个性化解释 | 不同深度与风格 | Tutor、双层画像、Prompt 参数 |
| 练习反馈 | 想「做会」 | 练习、错题、诊断、SRS-15 推荐 |
| 来源可信 | 担心编造 | 引用、Review、Wiki 版本 |
| 多模态 | 图解、课堂、语音 | 资源、OpenMAIC、TTS/ASR |
| 路径规划 | 先学什么 | 三策略路径、自进化 |
| 长期积累 | 知识沉淀 | Wiki、记忆、画像 |
| 过程可见 | 知道为什么 | Agent 日志、证据、风险等级 |
| 进度可视化 | 真实时长掌握度 | `learning_sessions`、学习分析 API |
| 拓展资料 | 课程库未覆盖 | SRS-16 `search_web` |

### 1.3.3 与通用 AI 差异

| 维度 | 通用 AI | 智学工坊 |
|---|---|---|
| 知识边界 | 参数记忆易幻觉 | 课程 RAG + Wiki 来源 |
| 学习闭环 | 单次问答 | 资料→Wiki→练习→诊断→策略 |
| 多智能体 | 概念宣传 | LangGraph + **24** 工具白名单 |
| 自进化 | 不可控 | 版本化、可回滚、有风险等级 |

## 1.4 学生学习闭环与 AI 结合点

![学生学习闭环总览](../assets/diagrams/01-learning-closed-loop.png)

`mermaid
flowchart LR
  A[课程资料上传] --> B[解析 / 切片 / 向量化]
  B --> C[课程知识库]
  C --> D[LLM Wiki / Tutor / 资源生成]
  D --> E[练习 / 错题 / 诊断]
  E --> F[画像 / 记忆 / 推荐 / 自进化]
  F --> G[学习路径更新]
  G --> D
  D --> H[Agent 日志 / Review / 来源追溯]
``

### 1.4.1 资料进入 — AI 抽取与 Wiki 生成

- 知识点：规则候选 → LLM 结构化归一化 → 确定性校验；单份资料最多 **30** 个有来源知识点。
- Wiki 生成仅处理当前资料绑定知识点，避免跨资料混入。

### 1.4.2 学习进行 — Tutor 与资源

- Tutor 个性化答疑、引用、讲解风格适配；Resource 生成文档/卡片/导图/课件。
- 快速寒暄走轻量路径；智能体模式经 Review。

### 1.4.3 练习反馈 — 诊断与练习推荐

- 错题归因、薄弱点、诊断建议；`PracticeSuggestionService` 从助手最近提问抽知识点推荐主题。

### 1.4.4 策略更新 — 推荐、路径、自进化

- 推荐刷新、三策略路径择优、自进化分析与物化；高风险需用户确认。

### 1.4.5 全链路留痕

写入 `agent_runs`、`llm_call_logs`、`wiki_page_versions`、`generated_resources`、`evolution_strategies`。

### 2.12.7 HybridRetriever 检索栈

RAG 已从单纯向量检索增强为：

1. **向量检索**（pgvector + HNSW）
2. **关键词检索**
3. **metadata GIN 过滤**
4. **轻量 rerank / source diversity**

Agent 工具 `search_course_knowledge` 封装上述能力，Tutor 与 Resource 共用检索结果并返回 citations。

### 2.12.8 知识点抽取流水线

`text
规则候选召回 → LLM 结构化归一化 → 确定性校验 / 规则降级
``

- 单份资料最多 **30** 个有来源细粒度知识点。
- 整理元数据记录 aliases、source chunk、置信度、降级原因。
- `/knowledge` 展示候选、合并、拒绝、保留与整理方式统计。

### 2.12.18 SRS-15 练习推荐实现说明

`PracticeSuggestionService`（`backend/app/services/practice_suggestion_service.py`）工作流程：

1. 读取 `/assistant` 最近用户提问（`agent_messages` 或 Tutor 会话）。
2. 使用 LLM 或规则从提问中抽取候选知识点。
3. 与课程 `knowledge_points` 对齐，过滤无归属或低置信条目。
4. 经 `GET /api/v1/quizzes/suggest-topics` 返回推荐练习主题列表。
5. `PracticePrepushService` 可将推荐入口预推送到练习页或桌宠提醒。

### 3.7.1 Wiki 用例步骤展开（TC-WIKI-001～003）

#### TC-WIKI-001 生成

1. 注册测试用户并登录，获取 JWT。
2. 创建课程 `course_id=C1`，上传一份 PDF 资料 `material_id=M1`。
3. 轮询 `GET /api/v1/materials/{M1}` 直至 `parse_status=done` 且 chunks>0。
4. 调用 `POST /api/v1/wiki/pages/generate-from-material`，body 含 `course_id`、`material_id`。
5. 断言响应 `code=0`，返回 `page_id`；数据库 `wiki_pages` 新增一行。
6. 断言 `wiki_page_versions` 版本号为 1，`change_type=create`。
7. 断言 `sources` JSON 含 `source_type=document` 与 `material_id`。

#### TC-WIKI-002 编辑与版本

1. 对 TC-WIKI-001 的 `page_id` 调用 `PUT /api/v1/wiki/pages/{id}` 修改 Markdown。
2. 再次 `GET versions`，断言版本号递增至 2。
3. 对比 v1 与 v2 的 `content_md` 差异非空。
4. 断言旧版本记录未被覆盖删除。

#### TC-WIKI-003 回滚

1. 调用 `POST /api/v1/wiki/pages/{id}/rollback`，指定 `target_version=1`。
2. 断言当前展示内容与 v1 一致。
3. 断言新版本链新增 rollback 记录，可追溯操作者。
4. `/knowledge` 页面手动确认 Wiki 详情显示回滚后标题与摘要。

# 第五篇 用户使用说明

> 面向学生用户的操作指南；路由以 2026-06-14 前端事实为准。

## 5.1 注册与登录

1. 打开 `http://localhost:3000/` 品牌首页。
2. 点击「登录/注册」弹窗，填写用户名、邮箱、密码。
3. 登录成功后跳转 `/home`；Token 存于浏览器 localStorage。
4. 未登录访问业务 API 返回 401，页面应提示重新登录。

## 5.2 课程与资料

1. 进入 `/courses`，点击创建课程，填写名称与描述。
2. 进入 `/knowledge`，选择课程，上传 PDF/PPT/Word。
3. 等待解析、切片、向量化状态变为完成（可刷新列表）。
4. 可选：访问公有《数据结构》模板课（只读）体验知识库。

## 5.3 知识空间与 Wiki

1. 在 `/knowledge` 对已完成资料点击「生成 Wiki」。
2. 打开 Wiki 详情，查看 Markdown、来源引用与关联知识点。
3. 编辑内容会生成新版本；可在版本历史中回滚。
4. 查看知识图谱子图，理解 prerequisite / similar 等关系。

## 5.4 AI 助手（/assistant）

### 5.4.1 快速模式

- 适合短问答；SSE 流式输出；显示引用来源。
- 可将回答保存到 Wiki；可对回答点赞/点踩反馈。

### 5.4.2 智能体模式

- 适合多步骤任务（生成练习、路径、课件、沉浸课堂等）。
- 展开时间线查看规划、工具执行、观察与 Review。
- 可暂停接收、恢复查看、取消任务、新建并行会话。
- 支持 `tool_hints` 指定工具；支持语音播放（TTS）。

### 5.4.3 常见口令示例

| 用户说法 | 系统行为 |
|---|---|
| 「根据资料解释二叉树」 | RAG + Tutor，强调引用 |
| 「帮我生成 5 道链表练习」 | QuizAgent + 练习落库 |
| 「生成互动课件」 | html-ppt-skill 多页课件 |
| 「生成沉浸课堂」 | OpenMAIC 后台任务 + MP4 |
| 「我薄弱点是图，帮我规划路径」 | PlannerAgent + 画像更新 |
| 「搜索最新考研动态」 | search_web 联网摘要 |

## 5.5 练习与诊断

1. 进入 `/practice`，选择课程，生成或继续练习。
2. 提交答案后查看解析与错题收录。
3. 查看历史诊断报告与薄弱点建议。
4. 若曾在助手提问，侧栏可能出现 **练习主题推荐**（`suggest-topics`）。

## 5.6 仪表盘与推荐

1. 进入 `/dashboard` 查看学习概览、推荐下一步。
2. 推荐卡片应展示 **理由**（关联画像、诊断或 Wiki）。
3. 外部资源 Feeds 可能在侧栏展示扩展阅读链接。

## 5.7 画像、路径与自进化

# 第六篇 AI Coding 与工程协作

> 说明本项目如何使用 Cursor/Codex 等 AI 编程助手，同时遵守 AGENTS.md 边界。

## 6.1 AI Coding 定位

AI 助手用于：**加速实现、补测试、同步文档、局部修复**；不用于自动改权限、migration 策略或生产密钥。

## 6.2 事实源优先级（人机共识）

`text
当前代码与运行结果
  → migration / Model / OpenAPI
  → docs/当前实现基线.md
  → 设计文档（表达目标，非实现事实）
``

## 6.3 推荐工作流

![AI Coding 工作流](../assets/diagrams/14-ai-coding-workflow.png)
<!-- 源码: docs/assets/diagrams/14-ai-coding-workflow.mmd -->

| 步骤 | 人 | AI |
|---|---|---|
| 1. 读任务 | 确认范围与验收 | 阅读 AGENTS.md + 基线 |
| 2. 改代码 | 审查 diff | 最小改动实现 |
| 3. 改 DB | 确认 migration | 生成 Model + revision |
| 4. 验证 | 跑 pytest/build | 汇报未执行项 |
| 5. 文档 | 答辩口径 | export_implementation_docs |

## 6.4 禁止事项（摘自 AGENTS.md §18）
### 6.3.1 典型 AI 辅助任务示例

| 任务 | AI 应产出 |
|---|---|
| 新增 API | Router → Service → Schema → pytest → export docs |
| 新增 Agent 工具 | service_tools 注册 → 风险级别 → test_agent_runtime |

- 自进化是否写 evidence 且可回滚
- 答辩数字是否与 pytest 实际一致
