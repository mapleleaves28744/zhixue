## 保留原则

以下类型保留为独立文档：

- FastAPI OpenAPI 自动生成的 API 模块摘要、完整接口清单和快照说明。
- SQLAlchemy metadata 自动生成的当前数据库清单。
- 阶段运行验收清单与真实 LLM/Next 安全专项验收记录。
- 本地开发启动指南、版本变更记录、文档事实源规则。
- 当前前端页面总览和路由设计。

其余空白占位主题已写入目录同名总文档，不再保留单独空文件。

## 自动检查

执行：

```powershell
python scripts/export_implementation_docs.py
python scripts/check_docs.py
```

`check_docs.py` 检查：

1. 每个编号目录存在同名总文档。
2. 每份总文档包含“目录导读”。
3. 不存在“待补充”占位模板。
4. 本地 Markdown 链接和明确的 `docs/*.md` 引用不存在断链。
