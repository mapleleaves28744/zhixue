## 给 AI 编程助手的强制阅读顺序

```text
当前代码与运行结果
  → 当前实现API清单 / 当前实现数据库清单
  → 当前实现基线 / 功能完成度 / 真实验收记录
  → 全面代码评估问题修复计划
  → 设计稿和历史方案
```

AI 必须遵守：

1. `当前实现基线.md`、自动生成 API/数据库清单和当前代码才是当前能力事实；
2. `19_测试方案` 中带日期的验收记录是当时快照，不自动代表今天仍已验收；
3. `superpowers/plans`、`superpowers/specs` 是实施计划和设计，不代表已经落地；
4. `_archive` 是历史归档，不得用于虚构当前接口、页面、表或功能；
5. `26_全面代码评估问题修复计划.md` 中的项目是待复现/待修复项，不能写成已经修复；
6. 比赛材料用于对外表达，若数字与代码冲突，以代码、自动清单和当前实现基线为准。
