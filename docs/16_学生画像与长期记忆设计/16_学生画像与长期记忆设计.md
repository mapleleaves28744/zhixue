## 画像内容

学生画像用于保存与学习直接相关的稳定特征，包括知识掌握情况、学习偏好、常见错误、解释风格偏好和当前学习状态。画像不是人格判断，也不保存无关敏感信息。

## 长期记忆

长期记忆记录可用于后续个性化的学习证据，例如反复出现的薄弱点、有效解释方式和阶段目标。记忆必须保留来源证据，并支持查看、反思更新和删除。

## 更新规则

- 作答与错题进入诊断，再作为画像和记忆更新证据。
- 重建画像通过 Profile Service/Agent 受控执行。
- Memory Agent 只总结学习相关事实，不绕过 Service 直接写数据库。
- 不因单次行为形成强结论；变化应能追溯到诊断或学习记录。

## 解释与隐私

前端应展示画像结论的证据和更新时间。学生只能访问自己的画像与记忆；删除操作保留必要审计但不继续用于推荐。当前已具备画像查看/重建、记忆查看/反思/删除 API，画像趋势展示仍需增强。
