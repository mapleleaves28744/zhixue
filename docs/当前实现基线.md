- 查询与审查按结构化结果验收，生成工具仍必须返回真实产物；资源请求支持可选 topic，将同工具多主题请求分别传递到生成模型。


- 快速问答和 Agent 共用会话 ID；Grounded Tutor 的非流式与流式模型调用均加载同课程、本人已完成的 user/assistant 回合。追问检索使用包含上文问题的消歧查询；旧 `[S#]` 标号不会被当作本轮引用。联网问答也写入会话消息。明确的“第 N 个链接/网页/搜索结果”在同会话最近已完成的网页引用中按序号定位，快速问答和 Agent 可读取该公开网页后再总结；缺少目标或正文时给出明确提示，Mock 模式仅展示标注过的正文摘录。Tutor 引用响应保留网页 URL，前端来源卡片可打开网页。对“上一题第 N 个选项”，同会话最近的 quiz 产物需再次校验用户、课程归属；仅题组中恰有一道题时解释真实题干、选项与已有解析，多题时请求澄清，避免依赖未持久化的题号顺序。对“刚才那份资料”，同会话最近引用的资料 ID 与 chunk ID 会重新校验本人、课程和切片归属；多份资料时请求澄清，只能读取前几个切片时明确标注范围。对“修改上个产物”，Agent 会校验同会话资源引用、本人和课程，仅修订文本类资源；修订创建新资源记录，previous_resource_id/revision_no 保留版本链，原版本不覆盖。
- 会话消息新增数据库顺序号；已完成回合可按连续边界投影到持久、有版本和长度上限的摘要，并保留原消息。摘要先形成确定性原话/产物摘录，后台模型再选择重要原文；保留 raw_summary 和来源索引，用版本比较拒绝过期摘要覆盖。Agent 排队任务按入队消息序号读取历史，避免执行时混入之后的新回合。快速问答与 Agent 的历史组装共用 UTF-8 字节保守 token 边界，优先保留本轮请求及最近完整回合，再按剩余预算放入早期摘录。明确的“后面/接下来”语言、详略、例子和“先给结论”要求形成带来源序号的会话约束；摘要投影保存规范值，排队任务按消息边界从原记录重建，旧摘要缺字段时可回填读取。仅本轮要求不进入会话约束；用户明确撤销时移除对应约束。
- 新增本地 30 轮确定性回归，实际执行摘要压缩后再加载 Tutor 上下文，覆盖开场目标保留、后发语言偏好覆盖、近期话题承接与本轮请求预算边界；该回归不替代真实模型多轮盲评或前端刷新/SSE 验收。
- `/assistant` 的会话缓存按用户与课程分隔；Agent 消息有可选 `client_request_id` 幂等去重。Tutor 请求有持久状态、租约和 `GET /api/v1/tutor/conversations/{conversation_id}/requests/{client_request_id}` 状态查询，快速模式的流式中断可查询已提交结果；旧客户端不带 ID 时仍按新请求处理。
- 记忆反思改为可认领、可重试的持久任务；学习记忆新增事实键、修订、来源证据、生命周期事件，用户遗忘形成 tombstone，热容量外记忆转 cold。召回只读当前课程和明确 global 范围，且在截断前按问题相关性排序。
- Agent 发送时写入 `IntentFrame v1` 规则候选（来源消息、独立子任务、主题、工具、排除项），显式 UI 工具选择与规则推断候选分开保存；完成后按实际工具调用和产物投影子任务状态。知识点缺失时会保存会话澄清草稿，下一条简短知识点回复可合并原请求；取消或入队失败时清理匹配的草稿，澄清回合不调用 LLM。Graph 拒绝无可验收产物却声称完成的任务；未知目标只暴露只读探索工具，错误候选会重新规划。Supervisor 的旧工具观察与成对工具结果以有界摘要送入模型，并预留工具 schema 和输出估算空间，原始结果仍保留；模型在 `length/error/aborted` 截断时不执行工具调用，并修复工具调用与结果配对恢复。
- 遗忘记忆会使相关会话摘要失效；自动上下文与重建摘要会排除其证据记录对应的问答回合，后台反思也跳过这些来源记录。当前预算由 `LLM_CONTEXT_WINDOW_TOKENS` 配置窗口、输出与工具 schema 预留、安全余量和 24k 上限计算；无 Provider tokenizer 时使用 UTF-8 字节边界裁剪历史；超长本轮必需输入要求拆分。会话约束首版只覆盖明确的语言、详略和例子要求，其他自由表达的早期约束仍可能丢失。对象绑定支持最近可见带 URL 网页引用、带持久顺序号的 quiz 题目、按序号或唯一标题定位资料及 Agent 文本资源修订；全文摘要分批读取全部已解析切片并分层合并，超过容量要求拆分。旧题顺序未知时澄清；不支持任意媒体资源修订。复杂意图已接入按需语义契约；任务修订采用取消并等待旧步骤结束后新建任务，保留最初来源与递增修订号。记忆冲突进入待确认，已知同义偏好被遗忘后不得自动重建；不确定同义候选留待确认。真实模型与页面验收见下方记录，不能将确定性开发样例等同于盲测准确率。
